    1. **Context shape:**
       ```ts
       interface FieldContextValue {
         id: string;          // generated via React.useId
         helperId: string;    // `${id}-helper`
         errorId: string;     // `${id}-error`
         hasError: boolean;
       }
       const FieldContext = React.createContext<FieldContextValue | null>(null);
       function useField() {
         const ctx = React.useContext(FieldContext);
         if (!ctx) throw new Error('Field subcomponents must be used inside <Field>');
         return ctx;
       }
       ```

    2. **Root `<Field>` component:**
       - Props: `{ children: React.ReactNode; error?: boolean; className?: string; id?: string }`
       - Generates ids via `React.useId()` if `id` not provided
       - Wraps children in `<div className={cn('flex flex-col gap-sm', className)}>` (UI-SPEC §"6. Field" Layout: vertical stack, gap --space-sm)
       - Provides `FieldContextValue` via Provider; `hasError = !!error`

    3. **`Field.Label`** — wraps `Label` from `./label` but auto-binds `htmlFor={ctx.id}`. Forward children & className.

    4. **`Field.Control`** — clones its single child element, injecting:
       - `id={ctx.id}`
       - `aria-describedby` = `ctx.hasError ? ctx.errorId : ctx.helperId` (only if helper or error exists; consumer responsible for rendering helper/error)
       - `aria-invalid={ctx.hasError ? true : undefined}`
       - Use `React.cloneElement(React.Children.only(children), { ...injectedProps })`
       - This is the magic that lets `<Field error><Field.Control><Input /></Field.Control></Field>` automatically apply error styling.

    5. **`Field.Helper`** — `<p id={ctx.helperId} className="text-xs text-fg-subtle">{children}</p>`. Returns `null` if `ctx.hasError` is true (UI-SPEC: "Error text takes precedence over Helper").

    6. **`Field.Error`** — only renders if `ctx.hasError`. Layout: `<p id={ctx.errorId} role="alert" className="text-xs text-destructive flex items-center gap-xs"><AlertCircle className="size-3" />{children}</p>`. `AlertCircle` from `lucide-react`.

    7. Attach subcomponents to root via assignment:
       ```ts

       Field.Helper = FieldHelper;

       ```
