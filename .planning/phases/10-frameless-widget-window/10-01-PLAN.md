   ```typescript
   export interface WindowPosition {

   }
   ```

3. **Store initialization** (D-12):
   ```typescript
   import Store from 'electron-store';
   interface StoreSchema {
     window?: { position?: WindowPosition };
   }
   const store = new Store<StoreSchema>();
   ```

4. **calculateInitialPosition()** function:
   - Use `screen.getCursorScreenPoint()` to get cursor position (D-02)
   - Use `screen.getDisplayNearestPoint(cursorPoint)` to get active display
   - Get `workArea` from display (taskbar-aware coordinates)
   - Try to restore saved position via `store.get('window.position')`
   - If saved position exists, validate with `isPositionValid()` (D-11)
   - If invalid or no saved position, calculate default bottom-right:
     ```typescript
     x: Math.round(workArea.x + workArea.width - WINDOW_SIZE - OFFSET)
     y: Math.round(workArea.y + workArea.height - WINDOW_SIZE - OFFSET)
     ```
   - Use `Math.round()` to avoid sub-pixel blur (D-04)

5. **isPositionValid()** helper (D-11):
   - Check if position is within current workArea bounds
   - Return false if x, y, or window size exceeds workArea
   - If invalid, log: "Saved window position is off-screen. Resetting to default bottom-right."

6. **savePosition(x: number, y: number)** function (D-09, D-10):
   - `store.set('window.position', { x, y })`
   - Only saves x,y (size is fixed at 128x128)
