    **Create `src/jarvis/core/screen.py`** with `ScreenAnalyzer` class:

    ```python
    class ScreenAnalyzer:
        """Handles vision routing and OCR/cloud fallback per D-04."""

        def resolve(self, image_b64: str, caps, settings=None) -> tuple[str, str | None, str | None]:
            """Determine best path for image analysis.

            Returns:
                Tuple of (strategy, image_b64_or_none, context_or_provider):
                - ("image", image_b64, None) -- model has vision, send image directly
                - ("ocr", None, extracted_text) -- OCR succeeded, send text to LLM
                - ("cloud", image_b64, provider_name) -- route to cloud vision model
                - ("error", None, error_message) -- no path available
            """
    ```

    Implementation logic (per D-04 fallback chain):
    1. If `caps.vision` is True: return `("image", image_b64, None)`
    2. Try OCR:
       ```python
       try:
           import pytesseract
           from PIL import Image
           from io import BytesIO
           import base64 as b64mod
           img_bytes = b64mod.b64decode(image_b64)
           img = Image.open(BytesIO(img_bytes))
           text = pytesseract.image_to_string(img, lang="por+eng")
           if text.strip():
               return ("ocr", None, text.strip())
       except ImportError:
           pass  # pytesseract not installed
       except Exception as e:
           logger.warning(f"OCR failed: {e}")
       ```
    3. Try cloud fallback -- check if cloud API keys are configured:
       ```python
       from jarvis.config import settings as default_settings
       s = settings or default_settings
       if s.anthropic_api_key:
           return ("cloud", image_b64, "anthropic")
       if s.openai_api_key:
           return ("cloud", image_b64, "openai")
       ```
    4. No path available:
       ```python
       return ("error", None, "Nenhum modelo com visao disponivel. Configure um modelo com vision, instale pytesseract, ou adicione uma API key de cloud (ANTHROPIC_API_KEY ou OPENAI_API_KEY).")
       ```

    Import `loguru.logger` at top. Do NOT import pytesseract at module level.
