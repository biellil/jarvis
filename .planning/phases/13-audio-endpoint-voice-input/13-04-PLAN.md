  <action>
    Connect PTT hotkey to recording flow per D-16 through D-19:

    In Widget.tsx:
    1. Add IPC listener for PTT events:
       ```typescript
       useEffect(() => {
         const handlePtt = (_event: any, action: 'start' | 'stop') => {
           if (action === 'start') {
             handleStartRecording();
           } else {
             handleStopRecording();
           }
         };
         window.electron?.ipcRenderer.on('ptt:action', handlePtt);
         return () => window.electron?.ipcRenderer.off('ptt:action', handlePtt);
       }, []);
       ```

    2. Move recording logic from TextInput to Widget:
       - Import useAudioRecorder
       - Import useOrbContext
       - Handle start/stop with orb state changes

    3. handleStartRecording (D-16):
       - Check if already recording
       - Call startRecording()
       - setState('listening')
       - Show tooltip "Gravando..." (from D-16)

    4. handleStopRecording (D-17, D-18):
       - const audioBuffer = await stopRecording()
       - setState('processing')
       - const result = await window.jarvis.sendAudio(audioBuffer)
       - If success: setState('responding'), show message
       - After 2s: setState('idle') (D-19)

    5. Error handling (D-12, D-15):
       - If recording error: setState('idle'), show error tooltip
       - NotAllowedError: "Permissão de microfone negada"
       - Conversion error: "Erro ao processar áudio"
