Adicionar ao `theme.extend` do tailwind.config.ts:

**Em `animation`**, após `'wake-burst-ring': 'wake-burst-ring 350ms ease-out'`:
```ts
'idle-breath': 'idle-breath 6s ease-in-out infinite',
```

**Em `keyframes`**, após o bloco `'wake-burst-ring'`:
```ts
'idle-breath': {
  '0%, 100%': { filter: 'hue-rotate(0deg) brightness(1.0)' },
  '25%':       { filter: 'hue-rotate(10deg) brightness(1.04)' },
  '50%':       { filter: 'hue-rotate(0deg) brightness(1.0)' },
  '75%':       { filter: 'hue-rotate(-10deg) brightness(0.97)' },
},
```

Rationale: `hue-rotate` com `±10deg` sobre o gradiente base do estado idle (azul-ciano-índigo) produz variação perceptível mas não agressiva. `brightness` oscila 0.97–1.04 para reforçar o efeito de "respiração" sem saturar. Duração 6s é o meio-ponto de "4–8s" do requisito. `filter` no Layer 1 não conflita com o `filter: drop-shadow` do root (que está um nível acima no DOM).

IMPORTANTE: NÃO usar `hue-rotate` no elemento root — ele afetaria o drop-shadow colorido (glow) junto com o gradiente da esfera, criando um efeito não intencional. A keyframe fica no Layer 1 (div interna) para isolar o efeito.

```tsx
// Antes:
const animationClass = {
  idle: 'animate-pulse-idle',
  listening: 'animate-pulse-listen',
  processing: 'animate-spin-process',
  responding: '',
}[state];

// Depois:
const baseAnimationClass = {
  idle: 'animate-pulse-idle',
  listening: 'animate-pulse-listen',
  processing: 'animate-spin-process',
  responding: '',
}[state];

// ORB-POL-03: idle breathing com hue drift ±10°.
// Condições para ativar:
//   1. state === 'idle' (outros estados têm sua própria animação com semântica clara)
//   2. !isPausedVisual — paused deve parecer quieto/adormecido, não "vivo"

// pulse-idle anima `transform: scale`, idle-breath anima `filter: hue-rotate`.
// CSS animations em propriedades diferentes compõem em paralelo sem conflito.
const animationClass = (state === 'idle' && !isPausedVisual)
  ? `${baseAnimationClass} animate-idle-breath`
  : baseAnimationClass;
```
