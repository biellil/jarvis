**Estratégia de crossfade — duas layers absolutamente posicionadas:**

```tsx
// ── Crossfade state tracking ─────────────────────────────────────────────
// ORB-POL-04: rastrear o gradiente anterior para fade-out enquanto
// o novo gradiente faz fade-in. useRef não causa re-render — apenas
// armazena o valor para uso no próximo render.
const prevStateRef = useRef<OrbState>(state);
const [displayedGradients, setDisplayedGradients] = useState({
  from: stateGradients[state],
  to: stateGradients[state],
  transitioning: false,
});

useEffect(() => {
  if (prevStateRef.current !== state) {
    const fromGrad = stateGradients[prevStateRef.current];
    const toGrad = stateGradients[state];
    prevStateRef.current = state;

    // Inicia crossfade: mostra "from" (opacity 1) e "to" (opacity 0)
    setDisplayedGradients({ from: fromGrad, to: toGrad, transitioning: true });

    // Após a transição CSS (400ms), marca como "não transitioning"
    // para que o layer "from" possa ser descartado visualmente
    const timer = setTimeout(() => {
      setDisplayedGradients({ from: toGrad, to: toGrad, transitioning: false });
    }, 420); // 20ms de folga sobre os 400ms do CSS transition

    return () => clearTimeout(timer);
  }
}, [state]);
```

**Substituir Layer 1 (a div única) por dois layers sobrepostos:**

```tsx
{/* ── Layer 1: Glass sphere body com crossfade (ORB-POL-04) ── */}
{/* Wrapper relativo para conter os dois sublayers */}
<div
  style={{
    position: 'relative',
    width: SIZE,
    height: SIZE,
    borderRadius: '50%',
    border: `1px solid ${innerBorder}`,
    boxShadow: 'inset 0 -20px 40px rgba(0,0,0,0.45), inset 0 6px 12px rgba(255,255,255,0.06)',
    transition: 'border-color 0.4s ease-in-out',
    overflow: 'hidden',
  }}
>
  {/* Sublayer A: gradiente "from" (fade-out durante transição) */}
  <div
    style={{
      position: 'absolute',
      inset: 0,
      borderRadius: '50%',
      background: displayedGradients.from,
      opacity: displayedGradients.transitioning ? 0 : 1,
      transition: 'opacity 400ms ease-in-out',
    }}
  />
  {/* Sublayer B: gradiente "to" (fade-in durante transição) — recebe animationClass */}
  <div
    className={animationClass}
    style={{
      position: 'absolute',
      inset: 0,
      borderRadius: '50%',
      background: displayedGradients.to,
      opacity: 1, // sempre visível — é o layer "destino"
      // Nenhuma transition de opacity aqui — controlado pelo Sublayer A sair
    }}
  />
</div>
```

**Justificativa de design:**
- Sublayer A tem o gradiente anterior e vai de `opacity: 1 → 0` durante `transitioning: true`
- Sublayer B tem o gradiente novo e sempre fica em `opacity: 1`
- Efeito visual: o antigo "desaparece" enquanto o novo já está embaixo visível
- Após 420ms, `transitioning` vira `false` e `from` é igualado a `to` — ambos mostram o mesmo gradiente, ready para a próxima transição
- `animationClass` (pulse-idle, animate-idle-breath, etc.) fica no Sublayer B que é o ativo

**ATENÇÃO:** remover a prop `transition: 'background 0.4s ease-in-out'` do style antigo (agora é `border-color` apenas, no wrapper). O `background` transition não funciona entre radial-gradients — era inócuo mas ruim de manter.
