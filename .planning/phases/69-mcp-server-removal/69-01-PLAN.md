<objective>
Apagar atomicamente todo o código fonte do MCP **Server** do `apps/backend-ts` — stdio transport, as 5 tools expostas (recall_memory, list_files, openFile, openFolder, viewContent), o tracker de client sessions e os testes correspondentes. O MCP Client (`apps/backend-ts/src/mcp/client/`) e a dependência `@modelcontextprotocol/sdk` permanecem intactos.

Purpose: Atender o requisito MCP-RM-01 (parte backend) — JARVIS deixa de ser um MCP Server. Como o scout (CONTEXT.md §scout_finding) confirmou que `createMcpServer` nunca é chamado em produção (zero call sites fora do próprio `server.ts` e dos seus testes), esta é uma deleção de dead code com zero risco runtime. Mesma filosofia cirúrgica do Phase 68 (D-05 do CONTEXT.md): apagar o que não é usado, manter o que importa.

Output: 5 arquivos + 2 diretórios apagados; estrutura `mcp/` reduzida a `mcp/client/` apenas; build/typecheck e teste e2e-mock-server.test.ts seguem verdes como gate de regressão MCP-RM-02.
</objective>
