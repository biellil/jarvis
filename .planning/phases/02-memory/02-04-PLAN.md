  </what-built>
  <how-to-verify>
    **Prerequisites:** Ensure an LLM is running (LM Studio or configured cloud provider).

    **Test 1 — Session persistence (MEM-01):**
    1. Run `python3 -m jarvis`
    2. Have a short conversation (2-3 turns about any topic)
    3. Type `exit` to quit
    4. Check: You see "Memorias salvas." message
    5. Verify SQLite: `sqlite3 data/jarvis.db "SELECT COUNT(*) FROM conversations; SELECT COUNT(*) FROM messages;"`
    6. Expected: At least 1 conversation and multiple messages

    **Test 2 — Semantic memory recall (MEM-02):**
    1. Run `python3 -m jarvis` (new session)
    2. Ask about the topic you discussed in the previous session
    3. Expected: JARVIS references or incorporates context from the earlier conversation

    **Test 3 — User profile (MEM-03):**
    1. In the same session, say "lembra que eu prefiro codigo em Python"
    2. Type `exit`
    3. Start a new session: `python3 -m jarvis`
    4. Ask JARVIS to write some code (without specifying language)
    5. Expected: JARVIS writes Python code (influenced by stored preference)
    6. Verify: `sqlite3 data/jarvis.db "SELECT * FROM user_profile;"`

    **Test 4 — Context coherence within session (CONV-06):**
    1. In a session, introduce a topic and have 3-4 turns about it
    2. On the 5th turn, reference something from the 1st turn
    3. Expected: JARVIS correctly references the earlier context

    **Test 5 — Data safety (MEM-05):**
    1. Verify ChromaDB data exists: `ls -la data/chroma/`
    2. Verify SQLite has no errors in loguru output during the session
  </how-to-verify>
