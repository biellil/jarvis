Key implementation details:

1. **FALLBACK_CONTEXT_WINDOW = 4096** — module-level constant. Used when `context_window` is None (Pitfall 3).

2. **`__init__` must initialize `self._conv_id`**: After storing `self._db = db`, call `self._conv_id = self._db.start_conversation() if db else None`. This is CRITICAL — both `_maybe_compress()` and `save()` require `self._conv_id` to exist. Without it, AttributeError at runtime.

3. **`send()` flow** (5 steps per Research Summary):
   ```
   Step 1: await self._maybe_compress()
   Step 2: memories = self._vectors.query_memories(user_input) if self._vectors else []
   Step 3: Build messages_to_send with injected memories (NEW list, never mutate history[0])
   Step 4: Append HumanMessage, stream LLM with messages_to_send, append AIMessage
   Step 5: Post-turn: add embedding to vectors, extract profile facts (after streaming)
   ```

4. **Memory injection** (D-01): Build `messages_to_send` as a NEW list. If memories exist, create a new SystemMessage with augmented content: `f"{SYSTEM_PROMPT}\n\nMemorias relevantes:\n{mem_block}"`. Inject profile facts from `db.get_profile_facts()` too. NEVER modify `self.history[0]`.

5. **`_maybe_compress()`** (D-04):
   - Use `count_tokens_approximately(self.history)` from `langchain_core.messages.utils`
   - Threshold: `int((self._context_window or FALLBACK_CONTEXT_WINDOW) * 0.75)`
   - If over threshold, take `self.history[1:-4]` (skip SystemMessage + keep last 4 messages)
   - Generate summary via LLM call: `await self.llm.ainvoke([SystemMessage("Summarize..."), *to_compress])`
   - Replace history: `[self.history[0], AIMessage(content=f"Resumo da conversa ate aqui: {summary}"), *self.history[-4:]]`
   - Save summary to SQLite: `self._db.save_summary(self._conv_id, summary)` — uses the conv_id obtained in `__init__`

6. **Post-turn profile extraction** (D-03, Pitfall 4):
   - AFTER `self.history.append(AIMessage(...))` and AFTER `print()` completes
   - Call `extract_profile_facts(self.llm, user_input)` 
   - For each fact: `self._db.upsert_profile(key, value, source)` and `self._vectors.add_memory(f"profile:{key}", ...)`
   - If `is_explicit_profile_command(user_input)`, use source="explicit"; else source="implicit"
   - Wrap entire block in try/except — never crash on extraction failure

7. **`save()`** method (D-02):
   - End conversation: `self._db.end_conversation(self._conv_id)`
   - Save all non-system messages: `self._db.save_messages(self._conv_id, [...])`
   - Add each message as embedding to ChromaDB: `self._vectors.add_memory(f"msg:{conv_id}:{i}", ...)`
   - Generate session summary if history > 4 messages, save to SQLite (MEM-04)

8. **Backward compatibility**: When `db=None` and `vectors=None`, session works exactly as Phase 1 — no memory operations, no profile extraction, no save. `self._conv_id` is None.

For `tests/test_session_memory.py`: Use mock LLM (same pattern as test_session.py), mock MemoryStore (MagicMock), and mock MemoryVectors (MagicMock). Test the FLOW — that the right methods are called in the right order — not ChromaDB internals (those are tested in test_memory_vectors.py).

For `tests/test_session.py`: Existing tests MUST still pass. Since `__init__` has new optional params with defaults, existing `ChatSession(llm=mock_llm)` calls remain valid.
