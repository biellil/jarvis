```python
"""ChromaDB vector memory -- semantic search over past conversations and profile facts.

Per D-02: Uses sentence-transformers all-MiniLM-L6-v2 locally (22 MB, 384-dim, CPU).
Per MEM-05: Embedding model name stored in collection metadata for versioning.
"""
import chromadb
from chromadb.utils.embedding_functions import SentenceTransformerEmbeddingFunction
from loguru import logger

EMBEDDING_MODEL = "all-MiniLM-L6-v2"
COLLECTION_NAME = "jarvis_memories"
```

The class `MemoryVectors`:
- `__init__(self, chroma_path: str)` -- creates `chromadb.PersistentClient(path=chroma_path)` ONCE (per Research Pitfall 2), creates `SentenceTransformerEmbeddingFunction(model_name=EMBEDDING_MODEL, device="cpu", normalize_embeddings=True)`, and calls `self._client.get_or_create_collection(name=COLLECTION_NAME, embedding_function=self._ef, metadata={"hnsw:space": "cosine", "embedding_model": EMBEDDING_MODEL})`
- `add_memory(self, doc_id: str, text: str, metadata: dict | None = None) -> None` -- calls `self._collection.upsert(ids=[doc_id], documents=[text], metadatas=[metadata or {}])`. Wraps in try/except, logs with `logger.warning` on failure. Never raises.
- `query_memories(self, query_text: str, n_results: int = 5) -> list[str]` -- calls `self._collection.query(query_texts=[query_text], n_results=n_results)`. Returns `results["documents"][0] if results["documents"] else []`. Wraps in try/except, returns `[]` on error.

Create `src/jarvis/memory/profile.py` with the following exact structure:

```python
"""User profile extraction -- implicit and explicit fact learning.

Per D-03: Two modes of learning user preferences:
1. Explicit: User says "lembra que..." -- saved with source="explicit"
2. Implicit: Post-turn LLM analysis extracts facts -- saved with source="implicit"

Per MEM-03: Profile facts stored via MemoryStore.upsert_profile(key, value, source).
"""
import json
from loguru import logger
from langchain_core.messages import HumanMessage, SystemMessage
from langchain_core.language_models.chat_models import BaseChatModel
```

Constants:
- `EXPLICIT_TRIGGERS` -- list of Portuguese and English trigger phrases: `["lembra que", "lembre que", "lembre-se que", "minha preferencia e", "minha preferencia e", "eu prefiro", "eu gosto de", "eu odeio", "eu trabalho com", "eu uso", "eu moro", "meu nome e", "meu nome e", "remember that", "my preference is", "i prefer"]`
  NOTE: Include both accented and non-accented versions for "preferencia/preferencia" and "nome e/nome e"

- `EXTRACTION_PROMPT` -- template string with `{user_input}` placeholder. Instructs LLM to analyze user message, extract personal facts/preferences/habits as JSON key-value pairs with Portuguese keys. Must include examples showing input -> output mapping and empty result case.

Functions:
- `is_explicit_profile_command(text: str) -> bool` -- `text.lower().strip()` then check if it starts with any trigger in EXPLICIT_TRIGGERS. Returns True/False.
- `async def extract_profile_facts(llm: BaseChatModel, user_input: str) -> dict[str, str]` -- Calls `await llm.ainvoke([SystemMessage(...), HumanMessage(content=prompt)])`. Strips markdown code fences if response starts with "```". Parses JSON. Returns dict of string keys to string values. On any error (JSONDecodeError, LLM error, etc.), logs with `logger.warning` and returns `{}`. Never raises.
