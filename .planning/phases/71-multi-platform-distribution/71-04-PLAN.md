|-----------|----------|-----------|-------------|-----------------|

| T-71-04 | Tampering / Privilege Escalation | AppImage `--no-sandbox` flag bypasses Chrome sandbox on Ubuntu 24.04 AppArmor | accept (with documentation) | Necessary workaround per research Pitfall 3 for Ubuntu 24.04 AppArmor user-namespace hardening. README (Plan 71-06) will document the flag and its security trade-off. Safer alternatives (apparmor profile, chrome-sandbox setuid) explored in deferred plant-seed. |
| T-71-11 | Spoofing | Unsigned AppImage runs without verification | accept | DIST-FUT-02 deferred. Personal use + user controls own binary distribution. README warns. |
