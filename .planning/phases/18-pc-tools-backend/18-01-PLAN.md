```
set_brightness(level=70)         -> {"action": "set_brightness", "args": {"level": 70}}
list_processes()                 -> {"action": "list_processes", "args": {}}
```

ATENÇÃO:
- `delete_file` Python usa chave `path` dentro de args (NÃO `file_path`). TS idem.
- `list_processes.args` é objeto vazio `{}`, NÃO ausente.
- `search_files.directory` tem default `"."`.

Pattern LangChain.js para tool factory (do tools.ts existente):
```ts
import { tool } from '@langchain/core/tools';
import { z } from 'zod';

export function createOpenAppTool() {
  return tool(
    async ({ app_name }: { app_name: string }) => {
      return { action: 'open_app', args: { app: app_name } };
    },
    {
      name: 'open_app',
      description: 'Abre um aplicativo pelo nome...',
      schema: z.object({ app_name: z.string().describe('Nome do aplicativo a abrir') }),
    },
  );
}
```

Note: tool() retorna JSON-stringified result ao agent; o payload objeto é o "resultado da tool" para nosso uso (intercept no plano 03).
