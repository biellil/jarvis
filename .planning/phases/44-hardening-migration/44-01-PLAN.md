## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| renderer → main (IPC) | shell:open-system-settings vem do renderer (sandbox), precisa não aceitar URL como parâmetro |
| main → renderer (IPC broadcast) | voice-mode:switch-result é enviado do main — renderer não pode forjar este payload |
| tray.ts → systemPreferences | check de permissão é read-only, sem prompt ao usuário |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-44-01 | Tampering | tray.ts — settingsUrl | mitigate | URL é string literal hardcoded em tray.ts (`'x-apple.systempreferences:...'`) — nunca derivada de parâmetro IPC ou input externo. Renderer não pode influenciar qual URL é aberta. |
| T-44-02 | Tampering | ipc/voiceMode.ts — shell:open-system-settings | mitigate | Handler usa URL hardcoded internamente — não aceita nenhum parâmetro do renderer. `ipcMain.handle` ignora qualquer payload enviado; URL é constante no código. |
| T-44-03 | Tampering | renderer — voice-mode:switch-result | accept | Canal é main→renderer (one-way broadcast). Renderer não pode enviar mensagens neste canal. `ipcMain` não tem handler registrado para este canal. Risco: inexistente por design. |
| T-44-04 | Denial of Service | tray.ts — permissão 'not-determined' | mitigate | D-06: 'not-determined' é tratado como bloqueado — switch não ocorre. Usuário recebe toast informativo em vez de falha silenciosa. App não entra em estado quebrado. |
| T-44-05 | Privilege Escalation | shell.openExternal() | accept | `shell.openExternal()` com URL `x-apple.systempreferences:` não executa código arbitrário — apenas abre uma pane do System Settings. macOS sandbox valida o protocolo. Risco: baixo. |
</threat_model>
