## Interaction Contract

### 1. Provider Dropdown (LLM Provider Select)

**Behavior:**
- Dropdown shows 4 options: `"LM Studio (Local)"`, `"OpenAI"`, `"Anthropic (Claude)"`, `"Google Gemini"`
- Selection is immediate (no Save button required — Phase 49 apply-without-restart pattern)
- Selecting a provider triggers context token estimation (existing modal if overflow detected)

**Conditional rendering trigger:**
- When provider = `"lmstudio"`: Show only LM Studio URL input, hide all API key fields
- When provider = `"openai"`: Show OPENAI_API_KEY input, hide others
- When provider = `"anthropic"`: Show ANTHROPIC_API_KEY input, hide others
- When provider = `"gemini"`: Show GEMINI_API_KEY input, hide others

---

### 2. API Key Inputs (Conditional Fields)

**Appearance per provider:**

#### OpenAI
- **Label:** "OpenAI API Key"
- **Placeholder:** "sk-proj-…"
- **Helper text:** "Found at https://platform.openai.com/account/api-keys"
- **Error states:** 
  - "API key cannot be empty"
  - "Invalid API key format"
- **Rendering:** Only when `llmProvider === 'openai'`

#### Anthropic
- **Label:** "Anthropic API Key"
- **Placeholder:** "sk-ant-…"
- **Helper text:** "Found at https://console.anthropic.com/account/keys"
- **Error states:**
  - "API key cannot be empty"
  - "Invalid API key format"
- **Rendering:** Only when `llmProvider === 'anthropic'`

#### Google Gemini (NEW)
- **Label:** "Google Gemini API Key"
- **Placeholder:** "AIzaSy…"
- **Helper text:** "Get free API key at https://aistudio.google.com/apikey"
- **Error states:**
  - "API key cannot be empty"
  - "Invalid API key format"
  - "GEMINI_API_KEY inválida — usando LM Studio" (at runtime, if auth fails)
- **Rendering:** Only when `llmProvider === 'gemini'`

**Common field properties (all API keys):**
- `type="text"` (visible by default, executor may add show/hide toggle)
- `variant="error"` applied when `error={!!apiKeyError}`
- `aria-label="Gemini API Key"` (or respective provider)
- Responsive: Full width on all screen sizes
- Focus state: Cyan ring (#06B6D4) via Tailwind focus-visible:ring-accent-ring

**Conditional rendering mechanism (ExecutorToDecide):**
```tsx
{llmProvider === 'gemini' && (
  <Field error={!!geminiKeyError}>
    <Field.Label>Google Gemini API Key</Field.Label>
    <Field.Control>
      <Input
        type="text"
        value={geminiApiKey}
        onChange={(e) => setGeminiApiKey(e.target.value)}
        onBlur={validateGeminiKey}
        placeholder="AIzaSy…"
        aria-label="Google Gemini API Key"
      />
    </Field.Control>
    <Field.Helper>
      Get free API key at https://aistudio.google.com/apikey
    </Field.Helper>
    <Field.Error>{geminiKeyError ?? ''}</Field.Error>
  </Field>
)}
```

## Accessibility

**Keyboard navigation:**
- Tab order: LM Studio URL → Provider Select → Conditional API Key Input → (modal if overflow)
- Provider dropdown: Radix Select keyboard support (Enter/Space to open, arrow keys to select)
- API key inputs: Standard Input tab/focus behavior, password reveal toggle (if implemented) accessible via button

**Screen reader:**
- Section heading: semantic `<h1>` (or `<h2>` if nested under page `<h1>`)
- Field labels: `<label htmlFor={id}>` via Field.Label (auto-wired by Field context)
- Inputs: `aria-label="Gemini API Key"` for clarity when label text alone is ambiguous
- Error messages: `role="alert"` via Field.Error (auto-announced)
- Helper text: `aria-describedby={helperId}` on input when no error (auto-wired by Field context)
- Modal (overflow warning): `role="dialog"` aria-modal="true" aria-label="Provider switch warning" (existing pattern)
