## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Minimal icon/inline gaps (reserved for future) |
| sm | 8px | Compact spacing (reserved for future) |
| md | 16px | Control spacing within sections (gap between input groups, labels) |
| lg | 24px | Current section spacing (base padding — will increase to xl for between-section gaps) |
| xl | 32px | New section spacing (between PTT, Always-Listening, TTS, Whisper sections) |
| 2xl | 48px | Reserved for major layout breaks (future phases) |
| 3xl | 64px | Reserved for page-level spacing (future phases) |

**Current → Phase 47 Changes:**
- Between sections: space-y-6 (24px / lg) → **space-y-8 (32px / xl)** [REQUIRED for POLISH-01]
- Section headers (h2) margin-bottom: mb-3 (12px) → **mb-4 (16px / md)** [REQUIRED for breathing room]
- Within controls in TtsProviderSelect: space-y-3 (12px) → **space-y-4 (16px / md)** [REQUIRED for consistency]
- Outer padding: p-6 (24px / lg) → **p-6 stays** (maintains consistent margin from window edge)

Exceptions: None. All values are multiples of 4.

## Layout & Window Sizing

**Current dimensions:**
- Window width: 480px (CONSTRAINT: narrow, cramped)
- Window height: 520px (CONSTRAINT: fixed, no user resize)
- Frame: native frame (`frame: true`)
- Resizable: false (locked window size)

**Phase 47 target dimensions:**
- Window width: **600px** (baseline) or **640px** (premium, if timeline allows)
- Window height: **520px** (baseline, current fits) or **560px** (recommended margin)
- Frame: native frame (no change)
- Resizable: false (no change — locked sizing per design)

**Code location:** `apps/desktop/src/main/settingsWindow.ts` line 10–11

**Rationale:**
- 480px causes section controls to wrap awkwardly and spacing feels cramped
- 600px provides ~25% width increase, allowing section controls to breathe without radical redesign
- 640px gives premium spacing if content allows (verify in development)
- 520px height works for all current sections; 560px is safety margin for future content

## Visual Hierarchy & Readability

**Before Phase 47:**
- Sections blur together due to minimal spacing (space-y-6 = 24px)
- Section headers (h2) lack breathing room (mb-3 = 12px below heading)
- Controls packed tightly within sections
- Overall feel: cramped, utilitarian, default Electron

**After Phase 47:**
- Clear separation between sections (space-y-8 = 32px gaps)
- Each section header has distinct margin below (mb-4 = 16px)
- Controls have breathing room within sections (space-y-4 = 16px between input groups)
- Overall feel: intentional, readable, polished

**No color or typography changes needed.** Spacing alone improves visual hierarchy significantly.
