O modelo precisa ser baixado no **runtime stage** (não builder), pois o volume do docker-compose monta sobre o diretório de modelos. Quando o volume está vazio (primeira subida), o Docker popula com o conteúdo da imagem — portanto o modelo deve estar na imagem runtime.

**Adicionar no runtime stage, APÓS o `npm install --omit=dev` e ANTES do CMD:**

```dockerfile
# Pre-download whisper base model during build (DOCK-08)
# nodejs-whisper stores models in: node_modules/nodejs-whisper/cpp/whisper.cpp/models/
# The 'download' subcommand fetches ggml-base.bin (~142 MB) from HuggingFace.
# On docker compose up with an empty whisper-models volume, Docker seeds the volume
# from the image contents — model is available immediately, zero runtime download.
RUN npx nodejs-whisper download base

# Validate model exists and is non-empty
RUN test -f node_modules/nodejs-whisper/cpp/whisper.cpp/models/ggml-base.bin \
    && test -s node_modules/nodejs-whisper/cpp/whisper.cpp/models/ggml-base.bin \
    && echo "✅ whisper base model present: $(du -sh node_modules/nodejs-whisper/cpp/whisper.cpp/models/ggml-base.bin)"
```

**Onde inserir:** logo após o bloco de COPY das migrações e ANTES do `# Set environment defaults`. A ordem no runtime stage deve ser:
1. apt-get install (curl, ffmpeg, libsqlite3-dev)
2. COPY package.json + package-lock.json
3. npm install --omit=dev
4. COPY dist, migrations, whisper binary, models
5. **RUN npx nodejs-whisper download base** ← inserir aqui
6. **RUN test -f ... && echo** ← validação
7. ENV defaults
8. EXPOSE
9. CMD

**IMPORTANTE:** A linha existente que copia os modelos do builder já estará presente:
```dockerfile
COPY --from=builder /app/node_modules/nodejs-whisper/cpp/whisper.cpp/models/ \
    ./node_modules/nodejs-whisper/cpp/whisper.cpp/models/
```
O download via `npx nodejs-whisper download base` vai baixar ggml-base.bin para o mesmo diretório. Ambos podem coexistir — o COPY copia arquivos já existentes no builder (pode estar vazio), e o download adiciona ggml-base.bin. Se já houve download no builder, esta linha é redundante mas inofensiva.

**Nota de build time:** O download de ggml-base.bin (~142 MB) requer acesso à internet durante `docker build`. O Docker layer cache armazena o resultado — builds subsequentes sem mudanças no Dockerfile não baixam novamente.
