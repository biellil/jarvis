# Phase 9 — UI Design Contract

> Visual and interaction contract for v1.2 Desktop UI milestone (Phases 9-13).
> Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Phase 9 scope:** Bootstrap Electron scaffold — no visible UI rendered yet.
> **Visual features:** Implemented in Phases 10-13 (frameless window, Aether Orb, chat input, audio UI).

## Design System

| Property | Value |
|----------|-------|
| Tool | Tailwind CSS 4.x |
| Preset | Default Tailwind config with custom animation keyframes |
| Component library | Radix UI (headless primitives for accessibility) |
| Icon library | Lucide React |
| Font | Inter (geometric, modern, tech aesthetic) |

**Note:** No shadcn/ui (web-focused design system). Electron desktop widget requires custom glassmorphism effects and compositor-optimized animations that shadcn doesn't provide. Tailwind provides design tokens foundation; custom CSS handles visual effects.

## Color

### Semantic State Colors (Orb Animation)

| State | Color | Tailwind Token | Hex | Usage |
|-------|-------|----------------|-----|-------|
| Idle | Cyan ethereal | `cyan-500` | `#06B6D4` | Pulsing orb when no activity |
| Listening | Amber luminous | `amber-500` | `#F59E0B` | Pulsing orb during voice recording |
| Processing | Violet mystic | `violet-500` | `#8B5CF6` | Spinning + pulsing orb waiting for API |
| Responding | Blue electric | `blue-500` | `#3B82F6` | Ripple rings radiating from orb |

### Base UI Colors (60/30/10 Split)

| Role | Value | Usage (60/30/10) |
|------|-------|------------------|
| Dominant (60%) | `#0F172A` (slate-900) | Window background, dark base for glassmorphism |
| Secondary (30%) | `rgba(255,255,255,0.08)` (white 8% opacity) | Glassmorphism card backgrounds, input fields |
| Accent (10%) | State-dependent (see below) | **Reserved for:** Orb glow, active state indicators, CTA buttons |
| Destructive | `#EF4444` (red-500) | (unused in v1.2 — no destructive actions) |

**Accent Usage (10% Rule):**
- Orb box-shadow glow (state color at 60% opacity, 24px blur)
- Active input field border (cyan-500)
- Microphone recording indicator (amber-500 dot)
- **NOT used for:** Text color, general borders, hover states

## Visual Effects (Aether Style)

### Glassmorphism Treatment

Applied to: Chat input card, future settings panel

```css
.glass-card {
  background: rgba(255, 255, 255, 0.08);
  backdrop-filter: blur(12px);
  border: 1px solid rgba(255, 255, 255, 0.12);
  border-radius: 16px;
  box-shadow:
    0 4px 24px rgba(0, 0, 0, 0.24),
    inset 0 1px 0 rgba(255, 255, 255, 0.1);
}
```

### Orb Glow Effect

State-dependent glow (compositor-safe — uses box-shadow only):

```css
.orb {
  /* Base orb */
  width: 96px;
  height: 96px;
  border-radius: 50%;
  background: radial-gradient(circle at 30% 30%,
    rgba(255,255,255,0.3),
    var(--state-color) 70%
  );

  /* Glow (state color at 60% opacity) */
  box-shadow:
    0 0 24px var(--state-color-60),
    0 0 48px var(--state-color-40),
    inset 0 -12px 24px rgba(0,0,0,0.2);
}
```

**State color CSS variables:**
```css
/* Idle */
--state-color: #06B6D4;
--state-color-60: rgba(6, 182, 212, 0.6);
--state-color-40: rgba(6, 182, 212, 0.4);
```

### Animation Constraints (Compositor Thread)

**CRITICAL:** All animations MUST use compositor-only properties to prevent jank on 60fps target.

**Allowed:**
- `transform` (translate, scale, rotate)
- `opacity`
- `filter` (backdrop-filter)

**FORBIDDEN:**
- `width`, `height`, `top`, `left` (triggers layout)
- `background-color` (triggers paint — use opacity on pseudo-element instead)
- `box-shadow` animation (triggers paint — use opacity on shadow layer instead)

**Orb Animation Examples:**

```css
/* Idle pulse (2s loop) */
@keyframes pulse-idle {
  0%, 100% { transform: scale(1); opacity: 1; }
  50% { transform: scale(1.05); opacity: 0.9; }
}

/* Listening pulse (1s loop, faster) */
@keyframes pulse-listen {
  0%, 100% { transform: scale(1); opacity: 1; }
  50% { transform: scale(1.08); opacity: 0.85; }
}

/* Processing spin + pulse */
@keyframes spin-process {
  from { transform: rotate(0deg) scale(1); }
  50% { transform: rotate(180deg) scale(1.05); }
  to { transform: rotate(360deg) scale(1); }
}

/* Responding ripple (3 rings, staggered) */
@keyframes ripple {
  0% { transform: scale(1); opacity: 0.8; }
  100% { transform: scale(2.5); opacity: 0; }
}
```

## Copywriting Contract

| Element | Copy |
|---------|------|
| **Tray menu** | Show<br>Hide<br>Quit |
| **Empty state heading** | Ready to assist |
| **Empty state body** | Press Ctrl+Shift+J to activate JARVIS |
| **API connection error** | Connection failed. Check if services are running. |
| **Mic permission denied** | Microphone access required for voice input |
| **Processing state** | (no text — orb animation only) |
| **Listening state** | (no text — orb animation only) |

**Tone:** Direct, informative, minimal. No conversational fluff ("Oops!" / "Hmm...").

**Error format:** `[Problem]. [What to do next].` Always actionable.

## Accessibility

| Requirement | Implementation |
|-------------|----------------|
| **Keyboard navigation** | Tab through input → mic button → (no other interactive elements in v1.2) |
| **Focus indicators** | 2px cyan-500 outline with 2px offset on keyboard focus (not mouse click) |
| **Screen reader** | Orb state announced via `aria-live="polite"` region: "JARVIS is listening" |
| **Color contrast** | All text meets WCAG AA (4.5:1) — white text on slate-900 = 15.3:1 |
| **Touch targets** | Mic button 44×44px minimum (exceeds 24px WCAG AAA) |

**Note:** No ARIA labels on Orb itself (decorative, state conveyed via separate live region).
