  <what-built>
Complete vision pipeline across three entry points:
1. **VISION-01** — analyze_screen LangGraph tool: ask the LLM "o que está na minha tela?" → tool calls CAPTURE_SCREEN IPC → LLM analyzes with vision API
2. **VISION-02** — Image paste/drag in ChatInput: paste or drag image → thumbnail preview → send with message → LLM analyzes
3. **VISION-03** — Screenshot hotkey (CmdOrCtrl+Shift+S): press hotkey → screen captured → attached to chat → type question → LLM analyzes
4. **Settings** — "Vision Hotkeys" section visible with HotkeyRecorder for screenshot hotkey
  </what-built>
  <how-to-verify>
Start the app: `pnpm --filter @jarvis/desktop dev`

**Test 1 — VISION-01 (analyze_screen tool):**
1. Make sure an LLM provider with vision is configured (OpenAI gpt-4o, Anthropic claude-3, or Gemini)
2. Open a window with visible content (e.g., a webpage or file browser)
3. In the JARVIS chat, type: "o que está na minha tela?"
4. Expected: JARVIS calls the analyze_screen tool, captures the screen, and returns a description of what is visible
5. Expected time: under 5 seconds total

**Test 2 — VISION-02 (image paste):**
1. Copy any image to clipboard (screenshot with Cmd+Shift+4 or Win+Shift+S, or right-click image in browser → Copy Image)
2. Click the JARVIS chat input (⌨ button)
3. Paste with Ctrl+V (or Cmd+V on macOS)
4. Expected: thumbnail preview appears above the chat input (max 80px height, X button visible)
5. Type a question and press Enter
6. Expected: JARVIS analyzes the image and responds

**Test 3 — VISION-02 (image drag-drop):**
1. Find an image file in Explorer/Finder
2. Drag it onto the JARVIS chat input area
3. Expected: thumbnail preview appears (same as paste)

**Test 4 — VISION-03 (screenshot hotkey):**
1. Press CmdOrCtrl+Shift+S (or configured hotkey)
2. Expected: JARVIS window gains focus and chat input shows thumbnail preview of the screen
3. Type "descreva o que está aqui" and press Enter
4. Expected: JARVIS analyzes the screenshot

**Test 5 — Settings Vision Hotkeys:**
1. Open Settings (right-click tray → Settings or hotkey)
2. Look for "Vision Hotkeys" section in the nav
3. Expected: HotkeyRecorder field for "Screenshot Hotkey" is visible with default CmdOrCtrl+Shift+S
4. Record a new hotkey — confirm it updates

**Error case (optional):**
- On macOS, if Screen Recording permission is NOT granted:
  - Test 1 should return the Portuguese error message about system settings
  - Test 4 should show an error or no-op gracefully
  </how-to-verify>
