<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Tray click → VoiceModeManager.setMode() | Input vem de um item de menu do SO — o label/mode é definido estaticamente no código, não vem do usuário como string livre |
| VoiceModeManager.setMode() → IPC broadcast | main process envia para renderer — renderer apenas recebe, não pode invocar este canal |
| Renderer → ipc/voiceMode.ts | NÃO existe este sentido — broadcastModeSwitch é fire-and-forget main → renderer |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
