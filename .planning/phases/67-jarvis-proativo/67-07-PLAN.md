## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Desktop → POST /api/settings/quiet-hours | Config from Electron (trusted, but validate format) |
| Desktop → POST /api/settings/folder-watch | Path from Electron (validate existence + deny system paths) |
| Desktop → GET /api/proactive/stream | Authenticated by existing Bearer middleware on Express |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-67-02 | Spoofing | GET /api/proactive/stream | mitigate | Existing Bearer token middleware on Express gates all /api/* routes. Localhost-only binding (documented in config.ts — 127.0.0.1 binding means no external access). Single-user assumption: no multi-tenant risk. |
| T-67-03 | Tampering | POST /api/settings/folder-watch path | mitigate | `fs.existsSync(path)` checks path exists; reject if `!path.startsWith('/') && !path.match(/^[A-Z]:\\//)` (require absolute path); reject if path is '/', '/etc', '/sys', '/proc', 'C:\\Windows', 'C:\\System32'. |
| T-67-04 | Injection | POST /api/proactive/:id/ack | accept | parseInt validation ensures only numeric IDs reach DB; Drizzle parameterized query guards SQL injection. |
</threat_model>
