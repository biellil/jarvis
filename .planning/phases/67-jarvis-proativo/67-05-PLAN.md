  <behavior>
    **Normal hours (getQuietHoursConfig().enabled === false OR isInQuietHours() === false):**
    - startWatching('/path', cb): opens chokidar.watch with { ignoreInitial: true, persistent: true, depth: 0 }
    - On 'add' event: push { name: basename(filePath), path: filePath } into bufferFiles; reset debounce timer to 2000ms
    - When debounce fires: call onFolderEvent([...bufferFiles]); clear bufferFiles; debounceTimer = null
    - stopWatching(): clearTimeout(debounceTimer); clearTimeout(quietDeferTimer); await watcher.close(); watcher = null

    **During quiet hours (getQuietHoursConfig().enabled === true AND isInQuietHours() === true):**
    - On 'add' event during debounce callback decision: push file into quietBuffer instead of calling onFolderEvent
    - If quietBuffer was empty before this push: schedule a setTimeout for nextQuietEnd(now, end) ms from now
      — on fire: call onFolderEvent([...quietBuffer]); clear quietBuffer; quietDeferTimer = null
    - If quietBuffer was NON-EMPTY (timer already running): append file to quietBuffer, do NOT create a new timer
    - This means all files that arrive during a quiet window are aggregated into one emission at quiet end
    - The quiet defer timer is calculated ONCE on the first file added during quiet; late arrivals share the same timer

    **Interaction between debounce and quiet:**
    - The debounce timer fires FIRST (2s after last file added). Inside the debounce callback:
      - Snapshot: `const config = getQuietHoursConfig(); const now = new Date();`
      - If `config.enabled && isInQuietHours(now, config.start, config.end)`:
        → Append bufferFiles to quietBuffer; clear bufferFiles; debounceTimer = null
        → If quietDeferTimer === null: compute msUntilQuietEnd = nextQuietEnd(now, config.end).getTime() - now.getTime()
          and schedule: `quietDeferTimer = setTimeout(() => { onFolderEvent([...quietBuffer]); quietBuffer = []; quietDeferTimer = null; }, msUntilQuietEnd)`
      - Else (normal hours):
        → call onFolderEvent([...bufferFiles]); clear bufferFiles; debounceTimer = null

    **Error handling:**
    - chokidar 'error' event: console.error, do NOT rethrow (keep watching)

    **startWatching called twice:** await close() on existing watcher before opening new one; also clear quietDeferTimer + bufferFiles + quietBuffer

    **Test cases (required):**
    - Test: single file added (no quiet) → onFolderEvent called after 2s with [{name, path}]
    - Test: 3 files added within 1s each (no quiet) → onFolderEvent called once after last file + 2s, with 3 entries
    - Test: stopWatching before debounce timer fires → onFolderEvent NOT called
    - Test: startWatching twice with different paths → first watcher closed before second opens
    - Test: file added, debounce fires during quiet hours → onFolderEvent NOT called at 2s; quietBuffer populated; quietDeferTimer set
    - Test: file added during quiet → quiet ends → onFolderEvent called with aggregated buffer at quiet end
    - Test: 2 files added during quiet (different debounce batches) → both end up in quietBuffer; onFolderEvent called once at quiet end with both files
    - Test: stopWatching during quiet deferral → onFolderEvent NOT called, quietDeferTimer cleared

    **Debounce callback decision tree (the critical piece — implement exactly):**
    ```typescript
    this.debounceTimer = setTimeout(() => {
      const filesToProcess = [...this.bufferFiles];
      this.bufferFiles = [];
      this.debounceTimer = null;

      const config = this.getQuietHoursConfig();
      const now = new Date();

      if (config.enabled && isInQuietHours(now, config.start, config.end)) {
        // Defer to quiet end — append to quietBuffer
        this.quietBuffer.push(...filesToProcess);

        if (this.quietDeferTimer === null) {
          // First batch during this quiet window — set timer for quiet end
          const quietEndDate = nextQuietEnd(now, config.end);
          const msUntilQuietEnd = quietEndDate.getTime() - now.getTime();

          this.quietDeferTimer = setTimeout(() => {
            const buffered = [...this.quietBuffer];
            this.quietBuffer = [];
            this.quietDeferTimer = null;
            onFolderEvent(buffered);
          }, msUntilQuietEnd);
        }
        // If quietDeferTimer !== null, timer already running — just appended to quietBuffer
      } else {
        // Normal hours — fire immediately
        onFolderEvent(filesToProcess);
      }
    }, 2000);
    ```

    **stopWatching (clear everything):**
    ```typescript
    async stopWatching() {
      if (this.debounceTimer) { clearTimeout(this.debounceTimer); this.debounceTimer = null; }
      if (this.quietDeferTimer) { clearTimeout(this.quietDeferTimer); this.quietDeferTimer = null; }
      this.bufferFiles = [];
      this.quietBuffer = [];
      if (this.watcher) { await this.watcher.close(); this.watcher = null; }
    }
    ```

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-67-03 | Information Disclosure | FolderWatcher path | mitigate | Path validation happens BEFORE startWatching is called: (1) Settings UI validates fs.existsSync before saving; (2) IPC handler in Plan 67-08 validates path is non-empty and is absolute path before calling startWatching. Symlink following: chokidar default followSymlinks=true is acceptable for single-user desktop; deny system paths (/, /etc, /system) in IPC validator. |
| T-67-08 | Denial of Service | quietBuffer unbounded growth | mitigate | quietBuffer is in-memory only; folder_event files are ephemerally short-lived (quiet window max 24h). Cap at 1000 entries in quietBuffer append: `if (this.quietBuffer.length < 1000) this.quietBuffer.push(...filesToProcess)` — prevents runaway memory if user drops thousands of files during a very long quiet window. |
