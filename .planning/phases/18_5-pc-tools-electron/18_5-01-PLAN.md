<task type="auto" tdd="true">
  <name>Task 2: openChatStream com fetch + ReadableStream + reconnect backoff</name>
  <files>apps/desktop/src/main/sse-client.ts, apps/desktop/src/main/__tests__/sse-client.test.ts</files>
  <behavior>
    - Exporta `openChatStream(opts: {url: string, apiKey: string, message: string, onToken: (t: string) => void, onAction: (a: SseAction['payload']) => void, onEnd: () => void, onError: (err: Error) => void, signal?: AbortSignal, fetchImpl?: typeof fetch}): Promise&lt;void&gt;`.
    - Monta URL: `${url}?message=${encodeURIComponent(message)}`.
    - Chama `fetchImpl` (default `globalThis.fetch`) com headers `{Authorization: 'Bearer ' + apiKey, Accept: 'text/event-stream'}` e `signal`.
    - Lê body via `response.body.getReader()`, decoder TextDecoder, acumula buffer, extrai frames via `splitBuffer`, parseia via `parseFrame`, invoca `onToken` ou `onAction`.
    - Quando reader termina sem erro → tenta reconnect com backoff [1000, 2000, 4000, 8000, 16000, 30000, 30000...] ms. Reconnect é abortado se `signal.aborted`.
    - Qualquer erro de fetch → aguarda backoff e tenta de novo (até signal abort).
    - `onEnd` é chamado APENAS quando `signal.aborted` ou quando response retorna 4xx (não retentável: 400/401/403/404/429).
    - 5xx e network errors → retry.
    - Exporta também `computeBackoffMs(attempt: number): number` puro (testável).
  </behavior>
