<objective>
Implementar os 9 action handlers Linux nativos do Electron. Cada handler é uma função assíncrona pura `(args) => Promise<ActionResult>` que valida entrada, chama `child_process.execFile` (ou `fs.promises`) com timeout 30s, e retorna resultado estruturado.

Purpose: esses handlers são o coração do executor — traduzem payloads `{action, args}` em operações reais no Linux do usuário. Consumidos pelo 18_5-04.
Output: 9 arquivos de handler + validators + index barrel + suite vitest.

REGRA CRÍTICA DE SEGURANÇA: **NUNCA** usar `child_process.exec(string)`. **SEMPRE** `execFile(cmd, [arg1, arg2])` com args como array. Qualquer uso de `exec()` ou template strings com args do usuário é um bloqueador imediato.
</objective>

| Action | Comando/API | Args de entrada | Validação |

| set_brightness | execFile('brightnessctl', ['set', `${level}%`]) | {level: number} | 0 <= level <= 100 inteiro |
