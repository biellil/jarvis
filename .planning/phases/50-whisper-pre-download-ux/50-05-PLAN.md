**Mocks required:**
- `electron`: mock `ipcMain.handle`, `BrowserWindow` with fake `isDestroyed()` + `webContents.send`
- `../voiceInput/whisperResources`: mock `ensureWhisperModel`, `isWhisperModelCached`, `MODEL_SIZES_MB`
- `../voiceInput/whisperModelResolver`: mock `resolveWhisperModel`
- `../voiceInput/voiceHandler`: mock `setActiveWhisperModel`
- `../voiceInput/vramDetection`: mock `getDetectedVramMb` returning 0

**Test cases:**

1. **Cache hit path**: isWhisperModelCached returns true → handler broadcasts `{ status: 'success', percent: 100 }` immediately without calling ensureWhisperModel. Also calls setActiveWhisperModel.

2. **Download happy path**: isWhisperModelCached returns false → handler calls ensureWhisperModel with onProgress callback → onProgress emits progress broadcasts with `status: 'downloading'` → after resolve, broadcasts `{ status: 'success', percent: 100 }` → calls setActiveWhisperModel.

3. **Error path**: ensureWhisperModel rejects with `new Error('Network timeout')` → handler broadcasts `{ status: 'error', errorMessage: 'Network timeout' }` → does NOT call setActiveWhisperModel.

4. **AbortError path (model switch)**: ensureWhisperModel rejects with `new DOMException('Aborted', 'AbortError')` → handler silently returns (no error broadcast, no setActiveWhisperModel call).

5. **resolveWhisperModel called with option and vramMb**: Verify resolveWhisperModel is called with the option passed to the handler.

**Test structure:**
```typescript
import { describe, it, expect, vi, beforeEach } from 'vitest';

vi.mock('electron', () => ({
  ipcMain: { handle: vi.fn() },
  BrowserWindow: vi.fn(),
}));

vi.mock('../voiceInput/whisperResources', () => ({

  isWhisperModelCached: vi.fn().mockReturnValue(false),

}));

vi.mock('../voiceInput/whisperModelResolver', () => ({
  resolveWhisperModel: vi.fn().mockReturnValue('base'),
}));

vi.mock('../voiceInput/voiceHandler', () => ({
  setActiveWhisperModel: vi.fn(),
}));

// Note: dynamic import of vramDetection in whisper.ts means the top-level
// _detectedVramMb may be 0 in tests; that is acceptable.
```
