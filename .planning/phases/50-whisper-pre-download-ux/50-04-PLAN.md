**2. Add IPC listener useEffect (mount/unmount):**
```typescript
useEffect(() => {
  const unsubscribe = window.whisper.onDownloadProgress((payload: WhisperDownloadProgress) => {
    setWhisperDownloadState({
      status: payload.status,
      percent: payload.percent,
      downloadedBytes: payload.downloadedBytes,
      totalBytes: payload.totalBytes,
      errorMessage: payload.errorMessage,
    });

    if (payload.status === 'success' && payload.downloadedBytes === payload.totalBytes && payload.percent === 100) {
      // Cache hit path: show Toast (UI-SPEC "Cache Hit Toast")
      // Non-cache-hit success: the 1.5s success indicator is managed by the Progress primitive's status='success'
      // Distinguish cache hit by checking if downloadedBytes === totalBytes on first broadcast
      // (cache hit emits exactly one success event; downloads emit multiple downloading events first)
    }

    if (payload.status === 'success') {
      // Schedule clearing state after 1.5s (success indicator duration per UI-SPEC D-07)
      setTimeout(() => setWhisperDownloadState(null), 1500);
    }

    if (payload.status === 'error') {
      // Show detailed error Toast (UI-SPEC "Error Toast")
      showToast('error', `Download failed: ${payload.errorMessage ?? 'unknown error'}`);
    }
  });
  return unsubscribe;
}, []);
```

For cache hit detection: track whether we saw any `downloading` events before the `success` event.
A simpler approach: use a `useRef` flag `_sawDownloadingRef`. Set to true on `downloading` events, reset to false when starting a new download. On `success`, if `_sawDownloadingRef.current === false`, it was a cache hit → show "Model already cached" info Toast.

```typescript
const _sawDownloadingRef = React.useRef(false);
// In the listener:
if (payload.status === 'downloading') {
  _sawDownloadingRef.current = true;
}
if (payload.status === 'success') {
  if (!_sawDownloadingRef.current) {
    showToast('info', 'Model already cached');
  }
  _sawDownloadingRef.current = false;
}
```

**3. Replace the existing `onWhisperModelChange: setWhisperModel` handler with a new function:**
```typescript
function handleWhisperModelChange(v: WhisperModelOption): void {
  setWhisperModel(v);
  // Reset cache hit tracker for the new download
  _sawDownloadingRef.current = false;
  // Clear any previous error state
  setWhisperDownloadState(null);
  // Trigger immediate download (D-01)
  window.whisper.downloadModel(v).catch((err: unknown) => {
    const msg = err instanceof Error ? err.message : String(err);
    console.error('[SettingsLayout] whisper.downloadModel failed:', msg);
  });
}
```
