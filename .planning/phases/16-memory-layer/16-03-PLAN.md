       - Export `EMBEDDING_MODEL = 'Xenova/all-MiniLM-L6-v2'` and `EMBEDDING_DIM = 384`.
       - Module-level `let extractorPromise: Promise&lt;any&gt; | null = null;` — this is the singleton (load ONCE, never per-call; mirrors Python's "Created ONCE at session start" warning in vectors.py).
       - `export async function getEmbedder()`: if null, set `extractorPromise = pipeline('feature-extraction', EMBEDDING_MODEL)`, then await and return.
       - `export async function embedText(text: string): Promise&lt;Float32Array&gt;`: call extractor with `{ pooling: 'mean', normalize: true }`, return `output.data as Float32Array`. Matches Python's `normalize_embeddings=True`.

       - Wrap in try/catch; log and rethrow (unlike MemoryStore, embedding failures should propagate — caller decides).

    3. Strict-mode types: `@xenova/transformers` has its own types; if they're loose, use `unknown` + narrow at the call site rather than `any`.
