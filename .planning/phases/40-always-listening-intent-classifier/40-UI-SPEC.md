## Copywriting Contract

### Section Heading
**Copy:** "Always-Listening"  
**Rationale:** Matches phase name, parallel to "Push-to-Talk", "Text-to-Speech" section names

### Label
**Copy:** "VAD Silence Threshold"  
**Rationale:** Technical but clear; VAD = Voice Activity Detection (established term from Phase 29)

### Value Display
**Format:** "{value} ms"  
**Examples:** "300 ms", "500 ms", "800 ms"  
**Rationale:** Unit suffix makes unit explicit; right-aligned to separate from label

### Helper Text
**Copy:**
```
Silence threshold after speech ends. Lower = more responsive but may trigger
on breathing/clicks. Higher = patient but may miss end of phrase.
Typical: 400–600ms.
```
**Rationale:** Explains trade-off (responsiveness vs. patience) in plain language; gives context for range

### Reset Button
**Copy:** "Reset to Default (500ms)"  
**Rationale:** Explicit, shows default value; clarifies action

### Success Feedback
**Visual:** Flash animation on label (0.2s: white → cyan-500 → white)  
**Copy (optional toast):** "VAD threshold applied in real-time"  
**Rationale:** Confirms slider change has been sent to renderer via IPC; real-time emphasis differentiates from "save" semantics

### Edge Cases

| Case | Copy |
|------|------|
| Value < 300ms (clamped) | Slider silently clamps to 300; helper text does not warn |
| Value > 800ms (clamped) | Slider silently clamps to 800; helper text does not warn |
| IPC send fails | Toast error: "Failed to apply VAD threshold. Check Always-Listening mode is active." |
| Slider updated while Always-Listening disabled | Label text grayed out; helper: "(Apply in Always-Listening mode to preview)" |

## Runtime Behavior

### Real-Time Apply (VLISTEN-04)

**Trigger:** User moves slider thumb  
**Action sequence:**
1. Slider `onChange` fires → state updates synchronously in React
2. Value display label updates immediately (e.g., "500 ms" → "550 ms")
3. IPC message sent to main: `{ channel: 'always-listening:vad-threshold', ms: 550 }`
4. Main process updates store: `store.set('vadSilenceThresholdMs', 550)`
5. Main process dispatches renderer event: `'always-listening:vad-threshold'` with payload 550
6. Renderer AlwaysListeningEngine receives event → calls `reconfigureVadThreshold(550)`
7. Silero VAD session updated (negativeFramesToClose reconfigured)
8. Optional: Flash animation on label indicates applied

**No save button required** — contrast with TTS API key (requires explicit Save/Cancel).

### Load on Mount

**Sequence:**
1. Settings window renders SettingsForm component
2. useEffect fetches current settings: `window.settings.get()`
3. Response includes `vadSilenceThresholdMs` (from store, default 500 if not set)
4. Slider input `value` set to retrieved value
5. Value display label shows current value

**Default behavior:** If store has no `vadSilenceThresholdMs` field (e.g., v1.8 upgrade), use fallback 500ms in Settings UI and apply store set.

### Reset Button

**Trigger:** User clicks "Reset to Default (500ms)"  
**Action sequence:**
1. Button click fires `onClick` handler
2. Slider value programmatically set to 500: `setVadThresholdMs(500)`
3. State updates → slider visual updates → value display updates
4. IPC message sent: `{ channel: 'always-listening:vad-threshold', ms: 500 }`
5. Main/renderer applies threshold change (same as step 4–7 above)

**Visual feedback:** Button may show brief "Reset" → "Applied" label, or just the flash on the slider label.

## Input Validation

| Input | Rule | Behavior |
|-------|------|----------|
| Slider value < 300 | Out of range (min) | HTML range input prevents selection; clamped by `min="300"` attribute |
| Slider value > 800 | Out of range (max) | HTML range input prevents selection; clamped by `max="800"` attribute |
| Step size | Must be 50ms increments | `step="50"` ensures only valid thresholds; e.g., 300, 350, 400, … 800 |
| IPC payload | Number >= 300 && <= 800 | Main process clamps on receipt: `Math.max(300, Math.min(800, ms))` |

## Integration Points

### Settings Handler (IPC)

**File:** `apps/desktop/src/main/ipc/settings.ts` (new or existing)

**Handler signature:**
```typescript
ipcMain.handle('settings:get', async (): Promise<SettingsData> => {
  return {
    pttHotkey: store.getPttHotkey(),
    ttsProvider: store.getTtsProvider(),
    ttsApiKey: store.getTtsApiKey(),
    whisperModelOverride: store.getWhisperModelOverride(),
    vadSilenceThresholdMs: store.get('vadSilenceThresholdMs') ?? 500, // NEW
  };
});

ipcMain.handle('always-listening:vad-threshold', async (_, ms: number) => {
  const clamped = Math.max(300, Math.min(800, ms));
  store.set('vadSilenceThresholdMs', clamped);
  // Broadcast to renderer for runtime apply
  mainWindow?.webContents.send('vad:threshold-changed', clamped);
  return { success: true };
});
```
