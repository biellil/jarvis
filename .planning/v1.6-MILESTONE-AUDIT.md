## Cross-Phase Integration

**Result: All 15 requirements wired end-to-end. No broken links.**

### E2E Pipeline (USE_WHISPER_CPP=true)

```
Renderer: sendAudioAndHandle.ts:100
  → ipcRenderer.invoke('send-audio', buffer)
  → ipcMain.handle('send-audio') [chat.ts:160-168]
  → bifurcation: USE_WHISPER_CPP=true [chat.ts:187-196]
  → voiceHandler.handleAudio() [voiceHandler.ts:28-110]
    → audioNormalizer.ts (16kHz PCM)
    → whisper.cpp STT via getWhisperInstance()
    → fetch /api/chat (backend LLM)
    → TTS provider (Murf/ElevenLabs) → audioBase64
  → return to renderer
  → audio playback
```

All 6 steps verified in code. 47 unit/integration tests covering the pipeline (all passing).

### Key Cross-Phase Wiring Verified

- Phase 29 → 30: `getWhisperInstance()`, `normalizeAudioToWav()`, `initializeGpuDetection()` all consumed by voiceHandler.ts
- Phase 30 → 31: `handleAudio()` called from chat.ts bifurcation; VoiceHandlerDeps injected at startup (index.ts)
- Phase 31 → 32: Audio endpoints removed from gateway/backend-ts after IPC path validated E2E
- Feature flag (INFRA-02): 5 decision points in index.ts + chat.ts all gate on `USE_WHISPER_CPP`
