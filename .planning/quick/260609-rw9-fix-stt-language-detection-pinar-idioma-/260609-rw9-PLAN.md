está somente no faster-whisper. Porém vamos tornar ambos configuráveis para paridade.

3a. Adicionar função pública que stt.py chama após resolver o idioma:
```python
def set_language(language: str) -> None:
    """Set transcription language for whisper.cpp flags (ISO 639-1, e.g. 'pt', 'en').

    Updates _WHISPER_FLAGS in-place so all subsequent transcribe() calls use the new language.
    Called by stt.init_stt() after reading config.stt_language.
    """
    global _WHISPER_FLAGS
    _WHISPER_FLAGS = ["-l", language, "--no-timestamps", "-nt"]
```

3b. Remover o `-l pt` hardcoded da declaração original do `_WHISPER_FLAGS` e substituir
pela versão sem `-l` — o set_language() é quem o define no init:

```python
_WHISPER_FLAGS = ["-l", "pt", "--no-timestamps", "-nt"]  # default; overridden by set_language()
```
Nota: manter o default "-l", "pt" na declaração — set_language() sobrescreve. Isso garante
que se whisper.cpp for chamado diretamente sem passar por init_stt() (testes unitários), o

é a adição de `set_language()`.

```python
    stt_module._model = None
    stt_module._cpp_backend = None

    call_kwargs = model_instance.transcribe.call_args
```
