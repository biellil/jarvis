# Quick Task 260527-r8z: adicionar LM_OPENAI_MODEL e variáveis do Gemini ao .env e config

**Date:** 2026-05-27
**Status:** planned

## Goal

Seguindo o padrão de `LM_STUDIO_MODEL` (override de modelo para o provider lmstudio), adicionar:
- `LM_OPENAI_MODEL`: quando `LLM_PROVIDER=openai`, usa este modelo em vez de `LLM_MODEL`
- `GEMINI_MODEL`: quando `LLM_PROVIDER=gemini`, usa este modelo em vez de `LLM_MODEL`

Também documentar essas variáveis no `.env.example` raiz.

## Tasks

### Task 1: Adicionar campos ao envSchema (config.ts)

**Files:** `apps/backend-ts/src/llm/config.ts`

**Action:**
- Adicionar `LM_OPENAI_MODEL: z.string().optional().default('')` ao envSchema
- Adicionar `GEMINI_MODEL: z.string().optional().default('')` ao envSchema

**Verify:** envSchema contém `LM_OPENAI_MODEL` e `GEMINI_MODEL`

### Task 2: Atualizar factory.ts para usar os novos campos

**Files:** `apps/backend-ts/src/llm/factory.ts`

**Action:**
- Caso `openai`: trocar `cfg.LLM_MODEL` por `cfg.LM_OPENAI_MODEL || cfg.LLM_MODEL`
- Caso `gemini`: trocar `cfg.LLM_MODEL` por `cfg.GEMINI_MODEL || cfg.LLM_MODEL`

**Verify:** factory usa modelos específicos por provider quando disponíveis

### Task 3: Atualizar .env.example raiz

**Files:** `.env.example`

**Action:**
- Adicionar `LM_OPENAI_MODEL=` na seção OpenAI
- Adicionar `GEMINI_MODEL=` na seção Gemini

**Verify:** .env.example documenta as novas variáveis
