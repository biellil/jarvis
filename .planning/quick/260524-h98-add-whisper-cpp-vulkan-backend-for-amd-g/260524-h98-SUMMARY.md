# Quick 260524-h98: whisper.cpp Vulkan Backend for AMD GPU Summary

**One-liner:** whisper.cpp subprocess backend with AMD auto-detection, config-driven dispatch, and graceful faster-whisper fallback for AMD RX 7600 (RDNA3) on Windows.

## What Was Built

Additive STT backend layer that routes transcription to whisper.cpp when an AMD GPU is detected on Windows, enabling Vulkan-accelerated inference where ctranslate2 has no ROCm/Vulkan Windows wheel.

## Key Decisions

- **subprocess approach**: whisper.cpp is called as a subprocess (not ctypes/CFFI). Binary stays decoupled — user downloads official releases, no build step.
- **stdlib wave only**: `_write_wav()` uses only the stdlib `wave` module. No scipy or soundfile dependency added to the whisper.cpp backend path.
- **Default GGML model**: `large-v3-turbo-q5_0.bin` — best quality/size for AMD Vulkan. Falls back to user's `config.whisper_model` if explicitly set.
- **wmic detection**: `_detect_amd_windows()` calls `wmic path Win32_VideoController get Name` — present on all Windows without extra installs. Returns False on any error.
- **Graceful fallback**: If binary or GGML model not found, prints actionable PT-BR instructions (download URLs) and falls back to faster-whisper without crashing.

## User Setup Notes

whisper.cpp binary and model must be downloaded manually:

1. **Binary**: Download from https://github.com/ggerganov/whisper.cpp/releases
   - Extract `whisper-cli.exe` to `~/.jarvis/bin/`
   - OR set `whisper_cpp_binary` in `~/.jarvis/config.json` to the full path

2. **Model**: Download `ggml-large-v3-turbo-q5_0.bin` from https://huggingface.co/ggerganov/whisper.cpp
   - Place in `~/.jarvis/models/`

3. **Enable** (optional — auto-detected on AMD/Windows):
   - Set `stt_backend` to `"whisper_cpp"` in `~/.jarvis/config.json` to force it
   - Or leave as `"auto"` — auto-selects whisper.cpp on AMD Windows, faster-whisper elsewhere
