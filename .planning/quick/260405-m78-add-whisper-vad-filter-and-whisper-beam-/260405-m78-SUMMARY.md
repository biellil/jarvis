# Phase quick Plan 260405-m78: Add whisper_vad_filter and whisper_beam_size Summary

**One-liner:** Exposed `whisper_vad_filter` and `whisper_beam_size` as pydantic-settings fields, eliminating hardcoded values in `WhisperTranscriber._transcribe_sync`.

## Objective

Make VAD filtering and beam size configurable via environment variables so users can disable aggressive VAD (which silently discards valid speech) or tune beam search width without code changes.

## Changes Made

### src/jarvis/config.py
Added two fields to `Settings` after `whisper_language`:
```python
whisper_vad_filter: bool = Field(default=True)   # WHISPER_VAD_FILTER
whisper_beam_size: int = Field(default=5)         # WHISPER_BEAM_SIZE
```

### src/jarvis/core/voice.py
- `WhisperTranscriber.__init__` now accepts `vad_filter: bool = True` and `beam_size: int = 5`
- Stores as `self._vad_filter` and `self._beam_size`
- `_transcribe_sync` uses `self._vad_filter` and `self._beam_size` (no more hardcoded values)

### src/jarvis/__main__.py
Updated `WhisperTranscriber` instantiation to pass new settings:
```python
transcriber = WhisperTranscriber(
    model_size=settings.whisper_model,
    language=settings.whisper_language,
    vad_filter=settings.whisper_vad_filter,
    beam_size=settings.whisper_beam_size,
)
```

### tests/test_voice.py
- `test_stores_config` extended to check `_vad_filter` (True) and `_beam_size` (5) defaults
- Added `test_stores_custom_vad_and_beam` — verifies non-default values stored correctly
- `test_calls_transcribe_with_language_and_vad` updated to use `vad_filter=False, beam_size=3` (proves not hardcoded)
- Added `test_default_construction_uses_vad_true_beam5` — backward compat guard
