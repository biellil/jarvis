<objective>
Expose `whisper_vad_filter` and `whisper_beam_size` as configurable settings instead of hardcoded values in WhisperTranscriber.

Purpose: VAD filter aggressively removes audio it classifies as "non-speech", which can silently discard valid speech (observed with teste.mp3). Making these configurable lets the user disable VAD or tune beam_size via env vars without code changes.

Output: Two new Settings fields, WhisperTranscriber constructor updated, wiring in __main__.py, tests updated.
</objective>
