## Technical Notes

### Event-Driven Cleanup Pattern
The cleanup follows Electron's lifecycle pattern:
```typescript
app.on('before-quit', () => {
  unregisterAll(); // Cleanup global shortcuts
  destroyTray();   // Cleanup tray icon
});
```

This ensures global shortcuts are unregistered before the app fully quits, preventing OS-level "hotkey already registered" errors on restart.

### Fallback Behavior
The hotkey module internally handles registration failures by:
1. Returning `false` from `registerHotkey()`
2. User can still activate via tray icon
3. Failure logged to console for debugging
