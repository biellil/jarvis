# Quick Task 260524-mg6: fix list_files not implemented open_file missing and jarvis label on continuation lines

## Context

Three bugs observed in JARVIS terminal output:

1. `[Erro: Unknown action: 'list_files']` — `list_files` action not in `execute_pc_action` switch in `pc_control.py`
2. `[jarvis]` label appears on every bullet/continuation line of multi-line responses — `at_line_start + main_stream` logic in `_read_sse_stream` prints the label on every new line after `\n`, not just the first token
3. `open_file` action missing — no way to open a file with default OS app; LLM has no tool for it either

Also: `set_volume`, `set_brightness`, `list_processes`, `search_files` are defined in `pc-tools.ts` (backend) but not handled in `execute_pc_action` (client).

## Tasks

### Task 1 — Fix `[jarvis]` label on continuation lines (chat.py)

**File:** `apps/desktop-py/src/jarvis_desktop/chat.py`  
**Lines:** ~307-329 (`_read_sse_stream`)

**Root cause:** `at_line_start` becomes `True` after every `\n` in a token. When `main_stream=True`, each new line prints `[jarvis]` label again.

**Fix:** Add `header_printed: bool = False`. Only print `[jarvis]` label when `main_stream and not header_printed`. After first label, set `header_printed = True`. All subsequent `at_line_start` triggers use `_RESPONSE_INDENT`.

```python
header_printed = False  # NEW

# in loop:
if at_line_start:
    if main_stream and not header_printed:
        console.print(f"{_LABEL_JARVIS} ", end="", highlight=False)
        header_printed = True
    else:
        console.print(_RESPONSE_INDENT, end="", markup=False, highlight=False)
    at_line_start = False
```

**Verify:** Multi-line responses show `[jarvis]` only on the first line; continuation lines indented by 9 spaces.

### Task 2 — Add missing PC actions to pc_control.py

**File:** `apps/desktop-py/src/jarvis_desktop/pc_control.py`

Add implementations and handlers for:

**`list_files(directory: str) -> list[str]`**
- Resolve alias (pt-BR/en folder names) via `_FOLDER_ALIASES`
- `sorted(item.name for item in resolved.iterdir())`
- Return list of filenames

**`open_file(path: str, config: JarvisConfig) -> None`**
- Validate path against whitelist (same as `read_file`)
- Windows: `os.startfile(str(resolved))`
- macOS: `subprocess.Popen(["open", str(resolved)])`
- Linux: `subprocess.Popen(["xdg-open", str(resolved)])`

**`search_files(pattern: str, directory: str = ".") -> list[str]`**
- `resolved.rglob(pattern)` — return relative paths as strings

**`set_volume(level: int) -> None`**
- Windows: pycaw `SetMasterVolumeLevelScalar(level/100.0)`
- macOS: `osascript -e "set volume output volume {level}"`
- Linux: `pactl set-sink-volume @DEFAULT_SINK@ {level}%`

**`set_brightness(level: int) -> None`**
- Use `screen_brightness_control.set_brightness(level)` if available
- Fallback: raise `ValueError("screen-brightness-control not installed")`

**`list_processes() -> list[dict]`**
- `psutil.process_iter(['pid', 'name', 'status'])` — return sorted list of dicts

**Add handlers in `execute_pc_action`:**
```python
elif action == "list_files":
    files = list_files(params.get("directory", "."))
    result["result"] = "ok"
    result["files"] = files
elif action == "open_file":
    open_file(params.get("path", ""), config)
    result["result"] = "ok"
elif action == "search_files":
    files = search_files(params.get("pattern", "*"), params.get("directory", "."))
    result["result"] = "ok"
    result["files"] = files
elif action == "set_volume":
    set_volume(params.get("level", 50))
    result["result"] = "ok"
elif action == "set_brightness":
    set_brightness(params.get("level", 50))
    result["result"] = "ok"
elif action == "list_processes":
    procs = list_processes()
    result["result"] = "ok"
    result["processes"] = procs
```

### Task 3 — Add open_file tool to pc-tools.ts

**File:** `apps/backend-ts/src/session/pc-tools.ts`

Add `createOpenFileTool()`:
```typescript
export function createOpenFileTool() {
  return tool(
    async ({ file_path }: { file_path: string }) => {
      return buildResult({ action: 'open_file', args: { path: file_path } });
    },
    {
      name: 'open_file',
      description:
        'Abre um arquivo com o aplicativo padrão do sistema. Use quando o usuário pedir para abrir ' +
        'um arquivo específico (ex: "abre o anotações.txt", "abre o relatorio.pdf"). ' +
        'Forneça o caminho completo ou relativo ao arquivo.',
      schema: z.object({
        file_path: z
          .string()
          .describe(
            'Caminho do arquivo a abrir. Pode ser absoluto (ex: "C:\\\\Users\\\\biel1\\\\Documents\\\\anotações.txt") ' +
            'ou simples nome se o diretório atual for conhecido.',
          ),
      }),
      responseFormat: 'content_and_artifact',
    },
  );
}
```

Add to `createAllPcTools()`:
