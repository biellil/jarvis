### Task 2 — Endpoint GET /debug/db-stats (commit `e00fcad`)

**Arquivo novo:** `apps/backend-ts/src/routes/debug.ts` (Express Router pattern,
seguindo o mesmo formato de `health.ts`).

**Wiring:** `app.ts` importa e monta `debugRouter` junto com `healthRouter`.
`index.ts` adiciona log de bootstrap `🛠️  Debug routes registered at /debug/*`.

**Reuso de conexão:** importa o singleton `db` de `apps/backend-ts/src/memory/db.ts` —
NÃO abre nova conexão SQLite (constraint atendida).

**Schema da resposta `GET /debug/db-stats`:**

```json
{
  "counts": {
    "conversations": 0,
    "messages": 0,
    "typed_memories": 0,
    "tool_calls": 0
  },
  "last_message": null,
  "database_path": "/app/data/jarvis.sqlite",
  "timestamp": "2026-04-26T19:00:00.000Z"
}
```

Quando há ao menos uma mensagem persistida, `last_message` retorna:

```json
{
  "id": 42,
  "conversation_id": 7,
  "role": "assistant",
  "content_preview": "Olá, como posso ajudar...",
  "created_at": "2026-04-26T18:59:58.123Z"
}
```

Erros internos retornam HTTP 500 com `{ error, message }`.
Sem autenticação — uso local apenas.
