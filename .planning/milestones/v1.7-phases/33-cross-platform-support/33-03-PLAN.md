<task type="checkpoint:human-verify" gate="blocking">
  <name>Task 2: Human verification on macOS</name>
  <what-built>
    macOS platform support:
    - app.dock.hide() added to index.ts — JARVIS lives in menu bar only, no Dock icon
    - electron-builder.yml bundles darwin-arm64 and darwin-x64 whisper prebuilds
    - README documents Linux X11 compositor requirement
  </what-built>
  <how-to-verify>
    Test on a macOS machine (physical or VM). Run dev mode for quick verification:

    ```bash
    # From monorepo root
    pnpm --filter @jarvis/desktop dev
    ```

    **PLAT-01 — Orb frameless window:**
    1. Launch JARVIS. Orb should appear in bottom-right corner.
    2. Verify: No title bar, no window frame visible.
    3. Verify: Dock icon does NOT appear in the macOS Dock (app.dock.hide() working).
    4. Verify: Orb shows drop-shadow and animations (same as Windows).

    **PLAT-03 — Tray icon in menu bar:**
    1. Look at macOS menu bar (top-right area).
    2. Verify: JARVIS tray icon appears in menu bar next to system icons.
    3. Right-click (or click) the tray icon.
    4. Verify: Context menu appears with "Pause listening", "Show", "Hide", "Configure Hotkey", "Configure PTT", "Quit".
    5. Click "Quit" — app exits cleanly.

    **PLAT-02 — Wake word pipeline:**
    1. Launch JARVIS with .env configured (JARVIS_API_KEY set, LLM provider configured).
    2. Say "Hey JARVIS" out loud (microphone required).
    3. Verify: macOS shows microphone permission prompt on first use — grant it.
    4. Verify: Orb wake burst animation (amber ring, scale 1.0→1.1→1.0).
    5. Verify: Orb transitions to listening (amber).
    6. Ask a question aloud.
    7. Verify: Orb transitions to processing (violet), then responding (blue), then back to idle.
    8. Verify: TTS audio plays.

    If wake word setup is not available, at minimum verify PTT works:
    - Press Ctrl+Space (or configured PTT hotkey)
    - Verify orb enters listening state
    - Speak a question, orb processes and responds

    **Document:** Note any issues observed. If Dock icon appears, or tray is missing, or wake word fails, describe the exact error/behavior.
  </how-to-verify>
  <resume-signal>
    Type "approved" if all three requirements (PLAT-01, PLAT-02, PLAT-03) are verified.
    Or describe specific failures for gap closure (e.g., "PLAT-01 OK, PLAT-03 OK, PLAT-02 fails with error: [paste error]").
  </resume-signal>
</task>

<task type="checkpoint:human-verify" gate="blocking">
  <name>Task 3: Human verification on Linux X11</name>
  <what-built>
    Linux X11 platform support:
    - frame: false + transparent: true already in BrowserWindow config (cross-platform)
    - electron-builder.yml bundles linux-x64, linux-x64-cuda, linux-x64-vulkan whisper prebuilds
    - tray.ts uses platform-agnostic Tray API (Electron handles AppIndicator automatically)
  </what-built>
  <how-to-verify>
    Test on a Linux machine with X11 and a compositor (GNOME/KDE/Cinnamon recommended). Run dev mode:

    ```bash
    # From monorepo root
    pnpm --filter @jarvis/desktop dev
    ```

    **PLAT-04 — Orb frameless window with transparency:**
    1. Launch JARVIS. Orb should appear in bottom-right corner.
    2. Verify: No title bar, no window frame visible.
    3. Verify: Orb background is transparent (you can see through it to the desktop).
    4. If orb appears as a black rectangle: compositor is not running. Start Picom: `picom -b`, then relaunch JARVIS.
    5. Verify: Orb shows drop-shadow and animations.

    **PLAT-06 — Tray icon in system tray:**
    1. Look at the system tray area (bottom taskbar or top panel, depending on DE).
    2. Verify: JARVIS tray icon appears.
    3. Right-click the tray icon.
    4. Verify: Context menu appears with "Pause listening", "Show", "Hide", "Configure Hotkey", "Configure PTT", "Quit".
    5. If tray icon is missing: verify `libappindicator` or `libayatana-appindicator` is installed.
       ```bash
       sudo apt install libayatana-appindicator3-1
       ```
       Then relaunch.

    **PLAT-05 — Wake word pipeline:**
    1. Launch JARVIS with .env configured.
    2. Say "Hey JARVIS" out loud.
    3. Verify: Orb wake burst animation fires.
    4. Ask a question — verify full STT → LLM → TTS cycle completes.
    5. Note: Linux usually does not show a microphone permission prompt (getUserMedia works implicitly).

    If wake word is not available, verify PTT works (Ctrl+Space → listening → response).

    **Document:** Note Linux distribution, desktop environment, compositor used, and any issues observed.
  </how-to-verify>
  <resume-signal>
    Type "approved" if all three requirements (PLAT-04, PLAT-05, PLAT-06) are verified.
    Or describe specific failures for gap closure (e.g., "PLAT-04 OK but tray missing on Ubuntu 24.04 — PLAT-06 needs fix").
  </resume-signal>
