# Milestone v2.0: Polish & Stability

**Status:** ✅ SHIPPED 2026-05-03
**Phases:** 45-47
**Total Plans:** 4

## Overview

Voice pipeline bug fixes (PTT mode guard, Whisper override), wake word reliability investigation and fix (mel normalization sign inversion), and Settings UI spacing polish.

## Phases

### Phase 45: Voice Pipeline Bug Fixes
**Goal**: The voice pipeline respects the active voice mode and uses the model the user selected in Settings
**Depends on**: Nothing (standalone bug fixes)
**Requirements**: PATCH-01, PATCH-02
**Plans**: 2 plans

Plans:
- [x] 45-01-PLAN.md — PTT voice mode guard (ptt-hotkey.ts + index.ts wiring + tests)
- [x] 45-02-PLAN.md — Whisper model override applied post-VRAM-detection (selectWhisperModel helper + index.ts + tests)

**Success Criteria:**
1. Pressing the PTT hotkey or PTT button in wake-word or always-listening mode does nothing
2. After setting a specific Whisper model in Settings, JARVIS uses that model for STT
3. The VRAM auto-detection still works correctly when override is "auto"

### Phase 46: Wake Word Reliability
**Goal**: "Hey JARVIS" activates reliably enough for everyday use
**Depends on**: Phase 45
**Requirements**: WW-01, WW-02
**Plans**: 1 plan

Plans:
- [x] 46-01-PLAN.md — Mel normalization fix + test environment fix (WakeWordEngine.ts + test)

**Root cause:** Mel normalization sign inversion (`x/10 - 2` instead of `x/10 + 2`) caused all embeddings to be out-of-distribution, producing near-zero classifier scores for any input.

**Success Criteria:**
1. Root cause identified and documented
2. After fix, "Hey JARVIS" activates on first or second attempt in quiet environment
3. False positive rate does not increase

### Phase 47: Settings UI Polish
**Goal**: The Settings window looks intentionally designed, not like a default Electron dialog
**Depends on**: Phase 45
**Requirements**: POLISH-01
**Plans**: 1 plan

Plans:
- [x] 47-01-PLAN.md — Settings window width + spacing polish (settingsWindow.ts + SettingsForm.tsx + TtsProviderSelect.tsx)

**Changes:**
- Window width: 480px → 600px
- Section gaps: `space-y-6` → `space-y-8`
- Heading margins: `mb-3` → `mb-4` (×4 h2s)
- TTS internal spacing: `space-y-3` → `space-y-4`

**Note:** Spacing polish addressed cramped layout but not the broader "looks like debug screen" feedback. Full Settings UX redesign deferred to v2.1.

## Milestone Summary

**Key Decisions:**
- Mel normalization fix in WakeWordEngine — corrected sign was root cause of all wake word failures
- PTT guard via setVoiceModeManager injection — null-safe, no circular import
- Whisper override applied post-VRAM-detection via selectWhisperModel helper

**Issues Resolved:**
- PTT hotkey firing in wrong voice modes
- Whisper Settings override being ignored
- Wake word "Hey JARVIS" not activating reliably
- Settings window cramped at default 480px Electron width

**Issues Deferred to v2.1:**
- Full Settings UX redesign — spacing alone doesn't fix "debug screen" aesthetic. Needs proper layout (sidebar nav + content), redesigned controls, visual identity.

**Technical Debt Incurred:**
- None notable
