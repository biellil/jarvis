Run the Electron app: `cd apps/desktop && npm run dev` (or equivalent dev command)

**Flow 1 — Provider select and UI update:**
1. Open Settings (hotkey or tray)
2. Navigate to "Text-to-Speech" section
3. Open the Provider dropdown — confirm "Kokoro (local)" option appears alongside ElevenLabs and Murf.ai
4. Select "Kokoro (local)"
5. Confirm: API Key field disappears, Voice ID field disappears
6. Confirm: "Download modelo" button appears with (~350 MB) size hint
7. Confirm: "Apenas local (sem fallback cloud)" toggle appears below KokoroSection
8. Switch back to ElevenLabs — confirm API Key field returns, kokoro UI disappears

**Flow 2 — Model download (requires internet):**
1. With Kokoro selected, click "Download modelo"
2. Confirm: button disappears, "Cancelar" button appears
3. Confirm: progress bar visible, percentage updates as download progresses
4. If you don't want to download 350MB, click "Cancelar" — confirm download stops and button returns to "Download modelo"

**Flow 3 — Text-only fallback when model not downloaded (D-03):**
1. Select Kokoro provider (without downloading model)
2. Send a voice or text message to JARVIS
3. Confirm: JARVIS responds with text but NO audio (no audio playback, no error crash)
4. Confirm: no API key errors, no cloud TTS attempted

**Flow 4 — Local-only mode behavior (D-05, TTS-OFF-05):**
1. Enable "Apenas local" toggle
2. Confirm: toggle state persists after closing and reopening Settings
3. (If model downloaded) Disable local-only → enable local-only → verify the setting persists on next app restart

**Flow 5 — Existing providers unaffected:**
1. Switch to Murf.ai or ElevenLabs
2. Confirm: API Key field, Voice ID, no Kokoro UI visible
3. If you have API keys configured, confirm TTS still works for Murf/ElevenLabs
