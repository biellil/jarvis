  <what-built>
    All proactive features end-to-end:
    - PROACT-01/02/03: Reminder creation via voice/text, TTS delivery, Electron Notification
    - PROACT-04: Quiet hours configuration and deferral
    - PROACT-05: Folder watch with 2s debounce notification
    - PROACT-06: Daily summary at configured time with TTS + bubble
  </what-built>
  <how-to-verify>
    Before testing: ensure JARVIS is running (backend-ts + Electron desktop).

    **Scenario A — Reminder (PROACT-01/02/03):**
    1. Type or say: "me lembra em 1 minuto de testar o sistema"
    2. JARVIS should reply with pt-BR confirmation: "Lembrete criado pra daqui 1 minuto: testar o sistema."
    3. Wait 60 seconds
    4. Verify: (a) Electron Notification appears with title "Lembrete" and body "testar o sistema"
    5. Verify: (b) TTS speaks "Lembrete: testar o sistema."
    6. Verify: (c) A proactive bubble appears in the chat with 🔔 icon and cyan left stripe

    **Scenario B — Quiet hours deferral (PROACT-04):**
    1. Go to Settings → Notificações proativas
    2. Enable "Horário silencioso", set Início to current time + 5 min, Fim to current time + 10 min
    3. Create a reminder for within the quiet window: "me lembra daqui 7 minutos de testar quiet"
    4. Wait until the reminder's due time (within quiet window) — verify: NO notification fires
    5. Wait until quiet hours end — verify: notification fires approximately at quiet end time

    **Scenario C — Folder watch (PROACT-05):**
    1. Go to Settings → Notificações proativas → enable "Monitorar pasta"
    2. Set path to a writable test folder (e.g., `/tmp/jarvis-test/` or `~/Downloads`)
    3. In a terminal, create a file: `touch /tmp/jarvis-test/test-file.txt`
    4. Within ~3 seconds (2s debounce + latency): verify Notification appears with title "Novo arquivo em jarvis-test"
    5. Verify: TTS speaks the file name in pt-BR
    6. Verify: bubble appears in chat with 📁 icon and green stripe

    **Scenario D — Daily summary (PROACT-06):**
    1. Go to Settings → Notificações proativas → Resumo diário
    2. Enable it and set Horário to 2-3 minutes from now
    3. Wait for the configured time
    4. Verify: Notification appears with title "Resumo diário pronto"
    5. Verify: TTS reads a natural pt-BR summary (3-5 sentences, informal tone)
    6. Verify: bubble appears in chat with 🌅 icon, cyan stripe, full summary text

    **Scenario E — List/cancel reminders (PROACT-01):**
    1. Create 2 reminders: "me lembra em 2 horas de reunião" and "me lembra em 3 horas de código"
    2. Ask: "quais lembretes tenho?"
    3. Verify: JARVIS lists both in pt-BR with approximate times
    4. Say: "cancela o da reunião"
    5. Verify: JARVIS confirms "Cancelado: reunião." and the reminder does not fire
  </how-to-verify>
