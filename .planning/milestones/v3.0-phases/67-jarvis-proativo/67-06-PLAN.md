  <behavior>
    buildSummaryContext(db, now: Date):
    - messagesSummary: SELECT content FROM messages WHERE role='user' AND createdAt > (now - 24h) LIMIT 20; format as numbered list of user turns truncated to 100 chars each; return "Nenhuma conversa nas últimas 24h." if empty
    - actionsSummary: SELECT action, path FROM actions_log WHERE timestamp > (now - 24h) LIMIT 10; format as "abriu Downloads/invoice.pdf (approved)"; return "Nenhuma ação executada." if empty
    - upcomingReminders: SELECT message, due_at FROM reminders WHERE status='pending' AND due_at > now AND due_at < (now + 24h) ORDER BY due_at; format as "Reunião às 14:00"; return "Nenhum lembrete." if empty

    generateDailySummary(llm, context):
    - Builds prompt from D-16 template (pt-BR, 3-5 sentences, informal tone, no bullets)
    - Calls llm.invoke([new HumanMessage(prompt)])
    - Returns response text (string)
    - On any error: returns "Não consegui gerar o resumo diário neste horário." (pt-BR fallback, never throws)

    Exact prompt template (D-16):
    ```
    Você é o JARVIS, assistente pessoal inteligente. Faça um resumo curto e natural do dia anterior em pt-BR (3-5 frases).
    Inclua: o que conversamos, ações que executei, e lembretes nas próximas 24h.
    Tom: parceiro próximo, não formal. Não use bullets nem listas.

    Conversas de hoje: {messagesSummary}
    Ações executadas hoje: {actionsSummary}
    Próximos lembretes (24h): {upcomingReminders}
    ```
  </behavior>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| DB data → LLM prompt | User message content inserted into LLM prompt context |
| LLM response → TTS + chat bubble | LLM output text forwarded to TTS and renderer |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-67-05 | Injection | buildSummaryContext: messagesSummary | mitigate | Truncate each user message to 100 chars (prevents prompt stuffing via long prior conversations). Limit to 20 messages. Use static labels "Conversas de hoje:" rather than dynamic LLM-formatted context field names. |
| T-67-05 | Injection | actionsLog paths in prompt | mitigate | File paths from actionsLog are local filesystem paths — not user-controlled inputs. Still: include only action type + basename(path) (not full path) to avoid leaking full directory trees into summary. |
</threat_model>
