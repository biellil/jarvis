**Status:** ✅ SHIPPED 2026-05-28

## Overview

## Phases

### Phase 82: LangGraph Execução Silenciosa sem Confirmação Obrigatória

**Goal:** Remover o nó de confirmação obrigatória do fluxo LangGraph: pular `interrupt` para tarefas já aprovadas anteriormente via memória de aprovações, confirmação quando necessária apenas por texto/chat, execução silenciosa — não anunciar que vai executar o plano, só retornar ação e resultado em texto.
**Depends on:** Phase 81
**Plans:** 3 plans

Plans:
- [x] 82-01-PLAN.md — Backend: approved_plans schema + approval.ts + graph.ts interrupt condicional
- [x] 82-02-PLAN.md — Python client: agentic_step_progress silent mode + config menu
- [x] 82-03-PLAN.md — Backend: ChatSession awaitingConfirmation + chat.ts confirmation routing

**Details:**
- `approved_plans` SQLite table com SHA-256 keying e TTL 90 dias
- `approval.ts` com 4 funções: `hasCriticalAction`, `canonicalPlanKey`, `isApprovedPlan`, `saveApproval`
- Nó planner em `graph.ts` com 3 caminhos: ações críticas → sempre interrompe, plano pré-aprovado → `task:auto-approved` silencioso, plano novo → interrupt + salva aprovação
- Python: `agentic_step_progress` field em `JarvisConfig`, filtro de step events em `_handle_agentic_event`, menu item 6 no `/config`
- Backend: `ChatSession.awaitingConfirmation` redireciona próxima mensagem do usuário para `graph.stream(new Command({ resume }))`
- 12/12 must-haves verificados (VERIFICATION.md: passed)
- Validated: APR-01, APR-02, APR-03, D-01..D-05, PY-02, PY-03, EVT-01, AWC-01..AWC-03

## Milestone Summary

**Key Decisions:**
- `approved_plans` com SHA-256 keying e TTL 90 dias — auditável, sem chave secreta, reset fácil por delete
- Langfuse self-hosted como default (Docker Compose) com cloud opt-in via env var — privacy-first
- SSE long-lived connection com heartbeat para Python client PC control — sem polling, zero overhead quando idle
- voice cloning scoped down para seletor preset — kokoclone não existe no PyPI; funcionalidade útil entregue sem bloquear milestone

**Issues Resolved:**
- LangGraph interrupt obrigatório em toda agentic task — resolvido com approval memory
- Electron dependency para PC control no Python client — resolvido com SSE fallback no gateway

**Issues Deferred:**
- Langfuse UI traces (human verification pendente) — requer Docker rodando localmente
- PC control E2E confirmation flow (human UAT pendente) — requer gateway + Python client rodando simultaneamente
- Voice cloning real (ECAPA-TDNN) — kokoclone indisponível no PyPI; mover para backlog se houver biblioteca alternativa

**Technical Debt Incurred:**
- `voice_cloning.py` existe com stubs mas sem implementação real — pode ser removido ou implementado no futuro
- `cloned_voice_path` field em JarvisConfig sem uso efetivo após simplificação do Phase 85
