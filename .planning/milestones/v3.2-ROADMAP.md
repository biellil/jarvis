## Overview

v3.2 entregou `apps/desktop-py/` — um cliente Python terminal-first que reutiliza o gateway/backend-ts existente para LLM + memória. Build incremental de 6 fases: infraestrutura → chat → STT → TTS → modos de voz → UI mínima.

Decisão central: Python thin client como alternativa ao Electron para ambientes sem GUI. Zero LangChain, zero ORB — apenas HTTP SSE para o gateway e pipeline local de voz.

---

## Key Accomplishments

1. **Python package scaffold** — `apps/desktop-py/` com uv + hatchling, `pnpm dev:desktop-py` wired no monorepo, config persistente em `~/.jarvis/config.json` via JarvisConfig (Pydantic BaseSettings)
2. **Terminal SSE streaming chat** — `chat.py` conecta ao gateway via urllib.Request/SSE sem deps externas; tokens streamam token-por-token; health gate no startup; saída limpa no Ctrl+C
3. **STT local com faster-whisper** — singleton `stt.py` com lock de thread, `record_until_silence()` via sounddevice + VAD automático, PTT via pynput GlobalHotKeys, suporte a 5 modelos (tiny→large-v3-turbo)
4. **TTS offline Kokoro + cloud fallback** — `tts.py` singleton: Kokoro offline (350 MB, sem API key), fallback automático ElevenLabs → Murf, modo `local_only`, `is_speaking()` para bloqueio de captura de voz
5. **State machine de 3 modos de voz** — `voice_modes.py`: PTT, wake_word (openwakeword + onnxruntime, threshold configurável), always-listening (VAD); hot-swap sem restart via `switch_mode()`; D-06 (bloquear captura durante TTS) enforced em todos os loops
6. **UI terminal rica** — `ui.py` via rich.Live: status line `[ MODE | MODEL | STATE ]` persistente no rodapé; `/config` menu: hot-swap de modelo Whisper, provedor TTS, modo de voz sem reiniciar

## Key Decisions

| Decision | Outcome |
|----------|---------|
| Python thin client, zero LangChain | LLM stays in backend-ts; Python client is pure HTTP wrapper |
| uv + hatchling | Faster than pip + setuptools; uv.lock committed for reproducibility |
| faster-whisper singleton with Lock | Thread-safe; hot-swap via reload_model() in Phase 77 |
| sounddevice over PyAudio | No build headers on Windows; numpy arrays native |
| openwakeword + onnxruntime | tflite-runtime not available on Windows/Python 3.12 |
| voice_modes.py state machine | Decouples capture logic from chat.py; chat only polls queue |
| rich.Live for status line | Non-blocking; paused during /config menu input |
