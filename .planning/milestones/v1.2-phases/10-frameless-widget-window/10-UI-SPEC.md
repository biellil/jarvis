## Copywriting Contract

Phase 10 introduces system-level UI (tray menu) and error states for position restoration.

| Element | Copy |
|---------|------|
| **Tray tooltip** | JARVIS |
| **Tray menu: Show** | Show |
| **Tray menu: Hide** | Hide |
| **Tray menu: Quit** | Quit |
| **Position restore error (console log)** | Saved window position is off-screen. Resetting to default bottom-right. |
| **Window drag cursor (CSS)** | `cursor: grab` (idle), `cursor: grabbing` (active) |

**Tone:** Direct, minimal. Tray menu labels match Windows/macOS system conventions (single-word verbs).

**Error format:** `[Problem]. [Action taken].` (informational log only — no user-facing dialog in Phase 10).

## Visual Assets

### Tray Icon Specification

**Source:** D-05 (CONTEXT.md) — círculo azul com glow sutil (versão simplificada do Aether Orb)

**Required sizes:**
- 16×16px (100% DPI, standard Windows tray)
- 32×32px (200% DPI, high-DPI displays)

**Visual design:**
```
Circle:
- Diameter: 12px (16×16 canvas), 24px (32×32 canvas)
- Fill: Radial gradient from center
  - Center (30% 30%): rgba(255, 255, 255, 0.6)
  - Edge (100%): #06B6D4 (cyan-500)
- Border: none

Glow:
- Outer shadow: 0 0 4px rgba(6, 182, 212, 0.4)
- Blur: 4px Gaussian

Background:
- Transparent (PNG alpha channel)
```

**Export:**
- Format: PNG-24 with alpha
- File paths:
  - `apps/desktop/resources/tray/icon-16x16.png`
  - `apps/desktop/resources/tray/icon-32x32.png`
- Color profile: sRGB
- Compression: PNG optimizer (pngquant or oxipng for smaller size)

**Implementation note:** Electron Tray API automatically selects correct size based on display DPI. No code-level handling required — provide both files.

## Interaction Design

### Window Dragging (D-13 to D-16)

**Pattern:** Entire orb component is draggable via CSS `-webkit-app-region: drag`.

**Visual feedback:**
```css
/* Phase 11 will apply this to Orb component */
.orb-container {
  -webkit-app-region: drag;
  cursor: grab;
}

.orb-container:active {
  cursor: grabbing;
}
```

**Behavior:**
- Drag threshold: OS-native (Electron handles automatically — D-16)
- Click vs. drag: OS distinguishes (no JS needed)
- Drag anywhere on orb: moves entire window

**Phase 10 preparation:** Phase 10 does NOT implement dragging CSS (orb component doesn't exist yet). Phase 11 will apply `-webkit-app-region: drag` when Orb component is created.

### Tray Menu Interaction (D-06 to D-08)

**Trigger:** Single-click on tray icon (Windows/Linux default).

**Menu structure:**
```
JARVIS [tooltip]
├─ Show     [shows window if hidden]
├─ Hide     [hides window if visible]
└─ Quit     [app.quit()]
```

**No separators, no submenus, no icons** — D-08 specifies exactly 3 items for DESK-04 compliance.

## Phase 10 Specific Notes

### What's Visible

**At launch:**
- Transparent frameless window (128×128px) in bottom-right corner
- Tray icon in system tray with "JARVIS" tooltip
- Window background: slate-900 (#0F172A) — **no white flash** due to `show: false` + `ready-to-show`

**What's NOT visible:**
- No orb (Phase 11)
- No chat input (Phase 12)
- No text (Phase 12)

### What's Interactive

**Working in Phase 10:**
- Tray menu: Show, Hide, Quit
- Window dragging: **NOT yet** (orb component doesn't exist — Phase 11)
- Position persistence: Window position saved on quit, restored on launch

### Configuration Values

**From CONTEXT.md decisions:**

| Property | Value | Source |
|----------|-------|--------|
| Window size | 128×128px | D-03 |
| Screen offset | 16px | D-01 (2 × spacing-md) |
| Position rounding | `Math.round()` | D-04 |
| Monitor detection | `screen.getCursorScreenPoint()` | D-02 |
| Persistence key | `window.position` | D-12 |
| Save trigger | `before-quit` event | D-10 |
| Bounds validation | Reset to default if off-screen | D-11 |

### BrowserWindow Options (DESK-02)

```typescript
new BrowserWindow({
  width: 128,
  height: 128,
  show: false,                // Prevent white flash
  backgroundColor: '#0F172A', // slate-900 from Phase 9 color palette
  frame: false,               // Frameless
  transparent: true,          // Transparent background
  alwaysOnTop: true,          // Always on top
  skipTaskbar: true,          // Hide from taskbar/alt+tab
  resizable: false,           // Fixed size
  // ... Phase 9 security settings remain unchanged
});
```
