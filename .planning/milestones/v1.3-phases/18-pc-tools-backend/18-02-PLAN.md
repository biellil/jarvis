Em `store.ts`, na classe `ToolLogger`:

1. Adicionar método `logDispatch(toolName: string, params: Record<string, unknown>): number | null`:
   ```ts
   logDispatch(toolName, params) {
     try {
       const result = this.db
         .insert(toolCalls)
         .values({
           timestamp: nowIso(),
           toolName,
           paramsJson: params,
           outcome: 'dispatched',
           output: null,
           error: null,
         })
         .returning({ id: toolCalls.id })
         .all();
       return result[0]?.id ?? null;
     } catch (exc) {
       console.warn(`ToolLogger.logDispatch failed (${toolName}): ${(exc as Error).message}`);
       return null;
     }
   }
   ```

2. Adicionar método `updateOutcome(id, outcome, output, error)`:
   ```ts
   updateOutcome(
     id: number,
     outcome: 'success' | 'error' | 'cancelled',
     output: string | null,
     error: string | null,
   ): boolean {
     try {
       const res = this.db
         .update(toolCalls)
         .set({ outcome, output, error })
         .where(eq(toolCalls.id, id))
         .run();
       return (res.changes ?? 0) > 0;
     } catch (exc) {
       console.warn(`ToolLogger.updateOutcome failed (id=${id}): ${(exc as Error).message}`);
       return false;
     }
   }
   ```

3. O método `log()` existente permanece intocado (legacy compat — pode ser usado por testes antigos).
