<objective>
Estender o handler SSE de `GET /chat/stream` em `routes/chat.ts` para emitir `event: action\ndata: <json>\n\n` sempre que o agent invocar uma PC tool durante o stream. O mecanismo: o router registra um `OnToolDispatched` listener na ChatSession antes de iniciar o stream, escreve o evento action no response conforme invocações acontecem, e limpa o listener no finally.

Purpose: Esta é a ponte entre o backend e o cliente Electron (Fase 18.5). Sem isto, o Electron não sabe que precisa executar uma ação.
Output: Router SSE estendido + (possivelmente) `sendStream` refatorado para usar o agent (necessário porque a versão atual usa `llm.stream()` direto, pulando o agent e portanto as tools).
</objective>

<interfaces>
Estado atual `sendStream`: usa `llm.stream(history)` diretamente — NÃO passa pelo agent, logo nenhuma tool é invocada durante stream. Isso é incompatível com a Fase 18 porque o usuário espera que "abre o firefox" durante stream também dispare action.

Duas opções:

**Opção A (escolhida):** Reescrever `sendStream` para usar `agent.stream({messages}, {streamMode: 'messages'})` do LangGraph. Esse modo emite message chunks incluindo AIMessageChunks com tokens e ToolMessages com resultados. Filtramos só AIMessageChunk para yield tokens ao cliente. As tool calls acontecem internamente e disparam os listeners já do plano 03 normalmente.

**Opção B:** Manter `sendStream` com llm.stream() e criar método separado `sendStreamAgent`. Descartado — duplica lógica.

Protocolo SSE final:
```
data: Vou
data:  abrir
data:  o
event: action
data: {"tool_call_id":42,"action":"open_app","args":{"app":"firefox"},"requires_confirmation":false}

data:  firefox
data:  pra
data:  você

```

Cada event termina em `\n\n`. Eventos sem `event:` continuam sendo tokens puros.

```ts
router.get('/chat/stream', async (req: Request, res: Response) => {
  const message = req.query?.message;
  if (typeof message !== 'string' || message.length === 0) {
    res.status(400).json({ detail: 'message required' });
    return;
  }
  const release = lock.tryAcquire();
  if (!release) {
    res.status(429).json({ detail: BUSY_DETAIL });
    return;
  }
  res.setHeader('Content-Type', 'text/event-stream');
  res.setHeader('Cache-Control', 'no-cache');
  res.setHeader('Connection', 'keep-alive');
  res.flushHeaders();

  session.setDispatchListener((ev) => {
    const payload = {
      tool_call_id: ev.toolCallId,
      action: ev.action,
      args: ev.args,
      requires_confirmation: ev.requiresConfirmation,
    };
    res.write(`event: action\ndata: ${JSON.stringify(payload)}\n\n`);
  });

  try {
    for await (const token of session.sendStream(message)) {
      res.write(`data: ${token}\n\n`);
    }
    res.end();
  } catch (err) {
    res.write(`data: [error] ${(err as Error).message}\n\n`);
    res.end();
  } finally {
    session.clearDispatchListener();
    release();
  }
});
```
