TypeScript target:
```typescript
export const COLLECTION_NAME = 'jarvis_memories';

export interface QueryResult {
  id: string;
  document: string;
  similarity: number; // 1 - cosine_distance, in [0, 1]
  metadata?: Record<string, unknown>;
}

export class MemoryVectors {
  constructor(chromaPath: string);
  init(): Promise<void>; // awaits client + collection creation; called automatically by add/query if not yet initialized
  addMemory(docId: string, text: string, metadata?: Record<string, unknown>): Promise<void>;
  queryMemories(queryText: string, nResults?: number, threshold?: number): Promise<QueryResult[]>;
}
```

ChromaDB JS client (chromadb &gt;=1.9):
```typescript
import { ChromaClient } from 'chromadb';
const client = new ChromaClient({ path: `file://${chromaPath}` }); // or PersistentClient depending on version
const collection = await client.getOrCreateCollection({
  name: COLLECTION_NAME,
  metadata: { 'hnsw:space': 'cosine', embedding_model: 'all-MiniLM-L6-v2' },
  // IMPORTANT: do NOT use Chroma's default embedding function. We pass embeddings ourselves.
});
await collection.upsert({ ids: [id], documents: [text], embeddings: [Array.from(vec)], metadatas: meta ? [meta] : undefined });
const results = await collection.query({ queryEmbeddings: [Array.from(qvec)], nResults: k });
```

Note: ChromaDB JS exposes `distances` as cosine distance (0 = identical, 2 = opposite). Convert: `similarity = 1 - distance`.
