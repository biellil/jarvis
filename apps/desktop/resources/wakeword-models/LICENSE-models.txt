Aplicabilidade no JARVIS
------------------------

JARVIS é declarado explicitamente em PROJECT.md como "assistente pessoal
inteligente para uso próprio" — uso não comercial, pessoal, sem
distribuição comercial. A licença CC BY-NC-SA 4.0 é COMPATÍVEL com esse
uso.

Caso o projeto mude para uso comercial no futuro, reavaliar:
  (a) treinar modelo custom "jarvis" standalone (planejado para v1.5+),
      removendo dependência dos modelos CC BY-NC-SA, OU
  (b) licenciar o modelo diretamente com os autores.
